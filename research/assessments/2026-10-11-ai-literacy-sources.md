## 1. Source and scope

논문은 최신을 따라가는 bare arXiv ID 대신 v1을 의도적으로 선택했다. Google과 Microsoft의 대상은 버전이 아니라 **2026-10-11 공개 문서 관찰**이다. 전체 페이지 스냅샷은 보관하지 않았으므로 동일 페이지 내용을 사후 완전히 재현할 수 없다. 이 기록과 연결된 전략 문서는 관찰 요약을 보존한다.

해결 절차는 `web.run`의 `open`으로 다음 URL을 요청하고 반환된 본문을 검토한 것이다. 동일 URL 재요청은 서비스 문서의 새 관찰이며 고정 버전 재현이 아니다.

- https://arxiv.org/abs/1804.04732v1
- https://support.google.com/gemini/answer/14286560?hl=ko
- https://support.google.com/gemini/answer/16275805?hl=ko

## 2. Observed shape

- MUNIT 초록은 이미지 변환의 다중 출력 가능성과 내용·스타일 표현 구분을 제시한다. 특정 현재 서비스의 구현 증거는 아니다.
- Google 도움말은 업로드 이미지 수정 기능을 안내하고 무료 기능 표에 이미지 생성을 표시한다. 이용 가능 여부·한도는 달라질 수 있다고 안내한다. 실제 사용자 계정에서 작동한 사실은 확보하지 않았다.
- Microsoft 도움말은 Word의 그림 압축과 잘린 영역 삭제를 설명한다. 이번 과제 문서를 5MB 이하로 만들었다는 증거는 아니다.

## 4. Evidence and limits

| 후보 | 보안·개인정보 | 운영·의존성 | 라이선스·유지관리 |
| --- | --- | --- | --- |
| 연구 개념 | 문헌 열람 외 새로운 경계 변화 관찰 없음 | 런타임·패키지 추가 없음. 초록 수준만 참고 | 전문·코드·그림 복제 없음. v1 고정 링크 유지 |
| 서비스 후보 | 실제 실행 시 사진 업로드 발생. 과제의 식별 정보 배제 필요 | 무료 계정 기능·한도 확인 필요. 이번 작업의 서비스 호출·이미지 생성 없음 | 약관 전문 미검토로 직접 도입 판단 불가. 실행일 기능 확인 필요 |
| Word 압축 개념 | 캡처 개인정보는 삽입 전 제거 권장 | 패키지 추가 없음. 실제 편집기 이용 가능 여부 미확인 | 도움말 화면·전문 복제 없음. UI는 버전별 재확인 |

실행한 확인은 로컬 과제 지시문 읽기와 공개 웹 문서 열람이다. 이미지 촬영·생성, 무료 계정 로그인, 원본 복원, 논문 재현, DOCX 생성·압축은 실행하지 않았다. 검색 단계에서 Palette 논문의 v1 페이지도 열었으나 최종 전략의 근거에서는 제외했다. 제3자 기사·포럼 주장은 채택하지 않았다.

## 5. Result and reconsideration condition

개념과 실행 후보의 평가를 기록했으며, 서비스 선택·실험은 아직 결정·실행된 사실이 아니다. 최종 서비스 선택은 수행자가 실제 계정에서 이미지 비교·생성·캡처가 무료로 가능한지 확인한 뒤 수행 전략에 기록할 사항이다. 알고리즘·API 직접 사용은 학교가 프로그램 실험을 요구하거나 웹 서비스로 조건을 충족할 수 없을 때 재검토한다.

이번 검토에서 새로운 공통 규칙은 얻지 않았다. 과제 지시문에 이미 있는 조건을 실행 절차로 풀어 썼으며 공유 규칙·외부 스킬 파일은 변경하지 않았다.
