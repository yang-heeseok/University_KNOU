## 📝 요약 (Summary)
1. 🔴 **구글 Colaboratory(Colab)**: 구글 클라우드의 가상 리눅스 서버 기반 주피터 노트북으로, Python·TensorFlow·Keras·NumPy가 사전 설치되어 있고 GPU/TPU를 무료로 사용할 수 있다. 일정 시간 미사용 시 가상머신이 초기화된다.
2. 🔴 **TensorFlow & Keras**: TensorFlow는 구글이 공개한 오픈소스 머신러닝 프레임워크이고, Keras는 TensorFlow를 백엔드로 사용하는 고수준 딥러닝 API로 현재 TF에 통합되어 있다. 역사적으로 Keras(v1~v2)는 TensorFlow·Theano·CNTK 세 가지 백엔드를 지원했으나, TF2.0(2019) 이후 `tf.keras`로 통합되었다. 2023년 발표된 Keras 3는 TF·JAX·PyTorch를 모두 백엔드로 지원한다.
3. 🟡 **MNIST 신경망**: 28×28 흑백 이미지(0~9 숫자, 훈련 60,000개/시험 10,000개)에 대해 완전연결 신경망(Flatten→Dense)과 CNN(Conv2D+MaxPool2D) 두 가지 방식으로 모델을 구성할 수 있다.
4. 🟡 **CIFAR-10 CNN**: 32×32 컬러 이미지(10개 분류, 훈련 50,000개/시험 10,000개)에 Conv2D+MaxPool2D+Dropout을 반복 적용하며, `padding='same'`으로 특성맵 크기를 유지하면서 더 깊은 네트워크를 구성한다.
5. 🟢 **Dropout**: 과적합 방지를 위해 학습 중 일부 뉴런을 무작위로 비활성화하는 기법으로, CIFAR-10처럼 복잡한 데이터에서 효과적이다.

## ✏️ 심화 학습 (Study Subject)

### 1. 가상 시나리오: "MNIST vs CIFAR-10, 어떤 모델을 선택해야 할까?"

- **상황**: 스타트업에서 손글씨 우편번호 인식 시스템(MNIST 유사)과 자동차 차종 분류 시스템(CIFAR-10 유사)을 각각 구축해야 한다.
- **문제**: 두 태스크에 동일한 단순 FCN을 사용해도 될까? 아니면 각각 다른 아키텍처가 필요한가?
- **해결**:
  - 손글씨 우편번호: 이진화된 단순 패턴 → FCN으로도 ~98% 달성 가능하나, CNN이 위치 변이에 강건
  - 차종 분류: 컬러, 텍스처, 복잡한 형태 → CNN + Dropout 필수, FCN은 과적합 심각
  - 결론: 이미지 복잡도가 높을수록 CNN + 정규화(Dropout) 조합이 필수
- **AI 학습 포인트**: "CIFAR-10에서 FCN만 사용했을 때 테스트 정확도가 얼마나 낮아지는지, 그 원인을 합성곱 연산의 특성(가중치 공유, 지역 수용장)과 연결해서 설명해 줘."

### 2. 관점별 비교 및 오개념 분석

**Keras vs TensorFlow 혼동 쌍**

| 구분 | TensorFlow | Keras |
| :--- | :--- | :--- |
| **정의** | 구글의 오픈소스 ML 라이브러리 | 고수준 딥러닝 API |
| **수준** | 저수준 (텐서 연산 직접 제어) | 고수준 (모델 레고 블록 조립) |
| **관계** | 백엔드 엔진 | TF 2.x에 통합 (`tf.keras`) |
| **코드 예시** | `tf.matmul(a, b)` | `model.add(Dense(128))` |
| **시험 출제 포인트** | "Keras는 TF를 백엔드로 사용" | "현재 TF와 결합되어 있음" |

- **오개념 1**: "Colab에서 작업한 파일은 영구적으로 구글 드라이브에 저장된다."
  - **분석**: 코드 파일(.ipynb)은 구글 드라이브에 저장되지만, 가상머신의 로컬 파일(업로드한 데이터, 설치한 패키지 등)은 세션 종료 시 초기화된다. `drive.mount()`로 드라이브를 연결해야 데이터를 영구 보존할 수 있다.

- **오개념 2**: "MaxPool2D는 학습 가능한 가중치가 있다."
  - **분석**: MaxPool2D는 단순히 지정된 윈도우 내 최댓값을 선택하는 고정 연산이다. 학습 가중치가 없으므로 역전파 시 파라미터 업데이트가 없다. Conv2D의 필터만 학습된다.

- **AI 학습 포인트**: "MaxPool2D 대신 Average Pooling을 사용하면 어떤 차이가 생기는지, 각각 언제 유리한지 실험 결과와 함께 설명해 줘."

**2. ⭐ [기억/이해] MNIST 데이터 설명**

> **해설**: MNIST는 28×28 픽셀의 **흑백(단채널)** 이미지이므로 나(컬러 이미지)는 틀렸다. CIFAR-10이 32×32 컬러 이미지이다. 훈련 60,000개, 시험 10,000개, 클래스 10개(0~9)는 모두 옳다.

<a id="prob-3"></a>
**3. ⭐⭐ [적용/분석] Keras 코드 빈칸**
> **정답: (A) Flatten, (B) 512, (C) 'softmax'**
> **해설**:
> - **(A) Flatten**: 28×28×1의 3D 텐서를 784 크기의 1D 벡터로 평탄화한다. FCN에 입력하기 위한 필수 변환.

<a id="prob-4"></a>
**4. ⭐⭐ [이해/분석] Dropout 층의 역할**
> **정답**: CIFAR-10은 MNIST보다 복잡한 컬러 이미지로, 네트워크가 훈련 데이터에 과적합되기 쉽다. Dropout은 학습 과정에서 일부 뉴런을 무작위로 비활성화(0으로 설정)하여, 네트워크가 특정 뉴런에 의존하지 않도록 강제한다. 이를 통해 다양한 부분 네트워크를 앙상블하는 효과를 내어 일반화 성능을 높인다.

<a id="prob-5"></a>
**5. ⭐⭐⭐ [적용/창조] padding='same' 역할과 이점**
> **정답**:
> - **역할**: `padding='same'`은 합성곱 연산 시 입력 특성맵 주변에 0을 채워(zero-padding) 출력 크기가 입력 크기와 동일하게 유지되도록 한다.
> - **이점**: 층을 깊게 쌓아도 특성맵이 급격히 축소되지 않아 더 많은 Conv2D 층을 연속 배치할 수 있다. 가장자리 정보 손실도 줄어든다.
> - **미사용 시 문제**: 3×3 필터 사용 시 매 Conv2D마다 특성맵이 2픽셀씩 줄어든다. 32×32 입력에 `padding='valid'`로 여러 층을 쌓으면 특성맵이 빠르게 소멸하여 깊은 네트워크 구성이 불가능해진다.

### 📌 심층 확장 — 혼합 정밀도 학습 (Mixed Precision Training)

#### A. FP16/FP32 혼합 사용 원리

딥러닝 모델의 기본 수치 정밀도는 FP32(32-bit float)이지만, 순전파·역전파를 FP16(16-bit)으로 수행하면 메모리와 연산 속도를 대폭 개선할 수 있다(Micikevicius et al., 2018).

**핵심 원칙:**

| 단계 | 정밀도 | 이유 |
| :--- | :--- | :--- |
| 순전파(Forward) | FP16 | 빠른 행렬 연산 (Tensor Core 활용) |
| 역전파(Backward) | FP16 | 기울기 계산 속도 향상 |
| **가중치 업데이트** | **FP32** | FP16은 표현 범위가 좁아 작은 기울기가 0으로 잘릴 위험 |
| Loss Scaling | FP32 | 기울기 언더플로우(underflow) 방지를 위해 손실값 스케일 확대 |

**효과:**
- 메모리: FP32 대비 약 **절반** (V100 16GB → 배치 크기 2배 가능)
- 속도: Tensor Core 지원 GPU에서 **2~3배** 향상
- 정확도: 올바르게 구현하면 FP32와 동등

```python
import tensorflow as tf

# -------------------------------------------------------
# 방법 1: tf.keras Mixed Precision API (TF 2.4+)
# -------------------------------------------------------
# GPU가 Compute Capability 7.0+ (V100, A100 등)인 경우 자동 Tensor Core 활용
policy = tf.keras.mixed_precision.Policy('mixed_float16')
tf.keras.mixed_precision.set_global_policy(policy)

print(f"연산 정밀도: {policy.compute_dtype}")   # float16
print(f"변수 정밀도: {policy.variable_dtype}")  # float32

# 모델 구성 (레이어는 FP16으로 연산, 가중치는 FP32로 저장)
model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(32, (3,3), activation='relu',
                           padding='same', input_shape=(32,32,3)),
    tf.keras.layers.MaxPool2D(2,2),
    tf.keras.layers.Conv2D(64, (3,3), activation='relu', padding='same'),
    tf.keras.layers.MaxPool2D(2,2),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(512, activation='relu'),
    tf.keras.layers.Dropout(0.5),
    # 주의: 출력층은 반드시 float32로 명시 (수치 안정성)
    tf.keras.layers.Dense(10, activation='softmax', dtype='float32')
])

# Loss Scaling 포함 컴파일
optimizer = tf.keras.optimizers.Adam(learning_rate=1e-3)
optimizer = tf.keras.mixed_precision.LossScaleOptimizer(optimizer)

model.compile(
    optimizer=optimizer,
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# -------------------------------------------------------
# 방법 2: PyTorch autocast + GradScaler
# -------------------------------------------------------
import torch
from torch.cuda.amp import autocast, GradScaler

# scaler: 기울기 언더플로우 방지를 위한 Loss Scaling 자동 관리
scaler = GradScaler()

def train_step_mixed_precision(model, optimizer, x, y, criterion):
    optimizer.zero_grad()
    with autocast():                        # FP16 순전파·역전파
        output = model(x)
        loss = criterion(output, y)
    scaler.scale(loss).backward()           # 스케일된 기울기 역전파
    scaler.step(optimizer)                  # FP32 가중치 업데이트
    scaler.update()                         # 스케일 인수 조정
    return loss.item()

print("혼합 정밀도 학습 설정 완료")
print("FP16 순전파 + FP32 가중치 업데이트로 메모리 절반, 속도 2~3배 향상")
```

> **주의 사항**: 출력층(Dense/Linear)의 dtype은 반드시 FP32로 설정해야 한다. FP16은 최댓값이 약 65,504에 불과하므로, Softmax 입력이 이를 초과하면 NaN이 발생한다. TF의 `set_global_policy`는 Dense 등 레이어 출력은 FP16으로 설정하지만, `dtype='float32'`를 명시한 레이어는 예외 처리된다.

### 📌 심층 확장 — Callbacks 조합 실용 예시

#### B. EarlyStopping + ModelCheckpoint + ReduceLROnPlateau

세 Callback을 조합하면 최적 모델을 자동으로 탐색·저장하면서 과적합을 방지할 수 있다.

| Callback | 주요 역할 | 핵심 파라미터 |
| :--- | :--- | :--- |
| **EarlyStopping** | 검증 손실이 개선되지 않으면 조기 종료 | `patience`: 몇 에폭 기다릴지 |
| **ModelCheckpoint** | 최적 검증 손실 모델을 파일에 저장 | `save_best_only=True` |
| **ReduceLROnPlateau** | 검증 손실 정체 시 학습률 자동 감소 | `factor`, `patience` |

```python
import tensorflow as tf

# -------------------------------------------------------
# Callbacks 조합 — CIFAR-10 완전 학습 예시
# -------------------------------------------------------
(x_train_c, y_train_c), (x_test_c, y_test_c) = tf.keras.datasets.cifar10.load_data()
x_train_c, x_test_c = x_train_c / 255.0, x_test_c / 255.0

model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(32, (3,3), activation='relu', padding='same', input_shape=(32,32,3)),
    tf.keras.layers.Conv2D(32, (3,3), activation='relu', padding='same'),
    tf.keras.layers.MaxPool2D(2,2),
    tf.keras.layers.Dropout(0.25),
    tf.keras.layers.Conv2D(64, (3,3), activation='relu', padding='same'),
    tf.keras.layers.MaxPool2D(2,2),
    tf.keras.layers.Dropout(0.25),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(512, activation='relu'),
    tf.keras.layers.Dropout(0.5),
    tf.keras.layers.Dense(10, activation='softmax')
])

model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# ① EarlyStopping: val_loss가 5에폭 이상 개선 없으면 중단, 최적 가중치 복원
early_stop = tf.keras.callbacks.EarlyStopping(
    monitor='val_loss',
    patience=5,
    restore_best_weights=True,  # 중단 시 최적 에폭의 가중치로 자동 복원
    verbose=1
)

# ② ModelCheckpoint: val_loss가 최저일 때만 모델 저장
checkpoint = tf.keras.callbacks.ModelCheckpoint(
    filepath='best_cifar10_model.keras',
    monitor='val_loss',
    save_best_only=True,          # 최적일 때만 저장 (디스크 절약)
    save_weights_only=False,      # 전체 모델 구조+가중치 저장
    verbose=1
)

# ③ ReduceLROnPlateau: val_loss가 3에폭 정체 시 학습률 × 0.5로 감소
reduce_lr = tf.keras.callbacks.ReduceLROnPlateau(
    monitor='val_loss',
    factor=0.5,          # 새 학습률 = 현재 × factor
    patience=3,          # 몇 에폭 기다릴지
    min_lr=1e-6,         # 학습률 하한선
    verbose=1
)

history = model.fit(
    x_train_c, y_train_c,
    epochs=100,                        # 충분히 크게 설정 (EarlyStopping이 결정)
    batch_size=64,
    validation_split=0.1,
    callbacks=[early_stop, checkpoint, reduce_lr]
)

# 학습 종료 후 최적 모델 평가
loss, acc = model.evaluate(x_test_c, y_test_c, verbose=0)
print(f"\n최적 모델 테스트 정확도: {acc:.4f}")
print(f"실제 학습된 에폭 수: {len(history.history['val_loss'])}")

# 저장된 모델 불러오기
best_model = tf.keras.models.load_model('best_cifar10_model.keras')
```

> **Callback 동작 흐름 예시**: 에폭 1~10에서 val_loss 감소 → 에폭 11~13 정체 → ReduceLROnPlateau 발동(lr: 1e-3 → 5e-4) → 에폭 14~16 소폭 개선 → 에폭 17~21 정체 → EarlyStopping 발동(5에폭 기다림) → 에폭 16의 최적 가중치 복원.

### 📌 심층 확장 — 모델 평가 지표 비교 및 시각화

#### C. 분류 평가 지표 비교

Accuracy(정확도)만으로는 클래스 불균형 데이터에서 모델 성능을 올바르게 평가할 수 없다. 예를 들어 클래스 A가 95%, B가 5%인 데이터에서 항상 A를 예측하는 모델도 Accuracy 95%를 달성한다.

| 지표 | 수식 | 강점 | 취약점 |
| :--- | :--- | :--- | :--- |
| **Accuracy** | $\frac{TP+TN}{TP+TN+FP+FN}$ | 직관적 | 클래스 불균형에 취약 |
| **Precision** | $\frac{TP}{TP+FP}$ | 거짓 양성 최소화 중요 시 | 거짓 음성 무시 |
| **Recall** | $\frac{TP}{TP+FN}$ | 거짓 음성 최소화 중요 시 (의료 진단) | 거짓 양성 무시 |
| **F1-Score** | $\frac{2 \times Precision \times Recall}{Precision + Recall}$ | Precision·Recall 균형 | 클래스별 중요도 차이 무시 |
| **Macro F1** | 클래스별 F1 단순 평균 | 모든 클래스 동등 취급 | 클래스 크기 무관 |
| **Weighted F1** | 클래스 크기 가중 F1 평균 | 클래스 불균형 반영 | 소수 클래스 성능 희석 |

```python
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from sklearn.metrics import (classification_report, confusion_matrix,
                             ConfusionMatrixDisplay, f1_score)

# -------------------------------------------------------
# CIFAR-10 모델 평가: 다양한 지표 + Confusion Matrix
# -------------------------------------------------------
# 데이터 준비
(x_train_c, y_train_c), (x_test_c, y_test_c) = tf.keras.datasets.cifar10.load_data()
x_test_c = x_test_c / 255.0
y_test_c = y_test_c.flatten()   # (10000, 1) → (10000,)

CIFAR10_CLASSES = ['airplane', 'automobile', 'bird', 'cat', 'deer',
                   'dog', 'frog', 'horse', 'ship', 'truck']

# 예측 (저장된 최적 모델 사용, 또는 위에서 학습한 model 사용)
# model = tf.keras.models.load_model('best_cifar10_model.keras')
y_pred_prob = model.predict(x_test_c, verbose=0)       # (10000, 10) 확률
y_pred = np.argmax(y_pred_prob, axis=1)                # (10000,) 클래스 인덱스

# ① 기본 Accuracy
accuracy = np.mean(y_pred == y_test_c)
print(f"Accuracy: {accuracy:.4f}")

# ② Precision / Recall / F1 (클래스별 + 전체)
print("\n--- 분류 보고서 (Classification Report) ---")
print(classification_report(y_test_c, y_pred,
                             target_names=CIFAR10_CLASSES))
# 출력 예시:
#               precision    recall  f1-score   support
#     airplane       0.81      0.84      0.82      1000
#  automobile       0.91      0.89      0.90      1000
#        bird       0.68      0.64      0.66      1000
#         ...
#     accuracy                           0.78     10000
#    macro avg       0.78      0.78      0.78     10000
# weighted avg       0.78      0.78      0.78     10000

# ③ Confusion Matrix 시각화
cm = confusion_matrix(y_test_c, y_pred)

fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# 원시 카운트 Confusion Matrix
disp = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=CIFAR10_CLASSES)
disp.plot(ax=axes[0], cmap='Blues', colorbar=False)
axes[0].set_title('Confusion Matrix (Count)', fontsize=13)
axes[0].tick_params(axis='x', rotation=45)

# 정규화된 Confusion Matrix (각 실제 클래스 기준 비율)
cm_norm = cm.astype(float) / cm.sum(axis=1, keepdims=True)
disp_norm = ConfusionMatrixDisplay(confusion_matrix=cm_norm,
                                    display_labels=CIFAR10_CLASSES)
disp_norm.plot(ax=axes[1], cmap='Blues', colorbar=False)
axes[1].set_title('Confusion Matrix (Normalized)', fontsize=13)
axes[1].tick_params(axis='x', rotation=45)

plt.tight_layout()
plt.savefig('cifar10_confusion_matrix.png', dpi=150, bbox_inches='tight')
plt.show()

# ④ 클래스별 F1 시각화 (막대 그래프)
f1_per_class = f1_score(y_test_c, y_pred, average=None)
plt.figure(figsize=(10, 4))
bars = plt.bar(CIFAR10_CLASSES, f1_per_class, color='steelblue', edgecolor='black')
plt.axhline(y=f1_per_class.mean(), color='red', linestyle='--',
            label=f'Macro F1 = {f1_per_class.mean():.3f}')
plt.xlabel('Class')
plt.ylabel('F1-Score')
plt.title('CIFAR-10: F1-Score per Class')
plt.xticks(rotation=30)
plt.legend()
plt.ylim(0, 1)
for bar, val in zip(bars, f1_per_class):
    plt.text(bar.get_x() + bar.get_width()/2, val + 0.01,
             f'{val:.2f}', ha='center', va='bottom', fontsize=9)
plt.tight_layout()
plt.savefig('cifar10_f1_per_class.png', dpi=150, bbox_inches='tight')
plt.show()
```

> **해석 가이드**: Confusion Matrix의 대각선이 진할수록 정분류가 많다. 비대각선 칸이 진하면 두 클래스 간 혼동이 심하다(예: 고양이/개, 새/비행기). F1이 낮은 클래스는 해당 클래스 데이터 증강이나 클래스 가중치(class_weight) 적용이 효과적이다.

### 4. (보완) 데이터 증강 (Data Augmentation)

훈련 데이터가 부족하거나 과적합이 심할 때, 기존 이미지를 변환해 **새 샘플처럼 사용**하는 기법이다. CIFAR-10처럼 클래스당 5,000장 수준의 데이터셋에서 특히 효과적이다.

```python
from tensorflow.keras.preprocessing.image import ImageDataGenerator

datagen = ImageDataGenerator(
    rotation_range=15,        # 최대 ±15도 회전
    width_shift_range=0.1,    # 수평 이동
    height_shift_range=0.1,   # 수직 이동
    horizontal_flip=True,     # 좌우 반전
    zoom_range=0.1            # 확대/축소
)
datagen.fit(x_train_c)

model_cifar.fit(
    datagen.flow(x_train_c, y_train_c, batch_size=64),
    epochs=50,
    validation_data=(x_test_c, y_test_c)
)
```

> **핵심**: 데이터 증강은 **학습 중에만** 적용하며, 검증/테스트 데이터에는 적용하지 않는다. 정규화(`/255.0`)는 증강 전에 수행해야 일관성이 보장된다. TF2.4+에서는 `tf.keras.layers.RandomFlip`, `RandomRotation` 등 전처리 층으로도 구현 가능하다.

> | 증강 기법 | 효과 | CIFAR-10 적합성 |
> | :--- | :--- | :--- |
> | 수평 반전 (horizontal flip) | 좌우 대칭 학습 | ✅ (자동차·비행기 등 좌우 무관) |
> | 랜덤 크롭 (random crop) | 위치 불변성 강화 | ✅ |
> | 컬러 지터 (color jitter) | 조명 변화 대응 | ✅ |
> | 수직 반전 (vertical flip) | 상하 반전 | ❌ (동물·자동차는 방향 있음) |

## 📖 심화 학습 예시 답안

#### 1. Keras Sequential API의 내부 동작 원리

모델이 `model.fit()`으로 학습되는 과정:

1. **순전파(Forward Pass)**: 입력 데이터가 층을 순서대로 통과하며 예측값 $\hat{y}$ 생성
2. **손실 계산**: `sparse_categorical_crossentropy`로 $L = -\sum y_i \log \hat{y}_i$ 계산
3. **역전파(Backward Pass)**: 각 층의 가중치에 대한 기울기 $\frac{\partial L}{\partial W}$ 계산
4. **가중치 업데이트**: Adam 옵티마이저로 $W \leftarrow W - \alpha \cdot \nabla_W L$ 적용
5. **에폭 반복**: 전체 훈련 데이터를 지정된 epochs만큼 반복

#### 2. FCN vs CNN 비교표

| 구분 | 완전연결 신경망 (FCN) | 합성곱 신경망 (CNN) |
| :--- | :--- | :--- |
| **입력 처리** | Flatten으로 1D 변환 필수 | 2D/3D 구조 그대로 처리 |
| **위치 정보** | 손실됨 | 보존됨 (지역 수용장) |
| **파라미터 수** | 매우 많음 (입력 크기에 비례) | 적음 (가중치 공유) |
| **이동 불변성** | 없음 | 있음 (translation invariance) |
| **MNIST 적합성** | 보통 (~98%) | 높음 (~99%+) |
| **CIFAR-10 적합성** | 낮음 (심각한 과적합) | 높음 (Dropout 조합) |
| **AI 활용** | 정형 데이터 분류 | 이미지, 영상, 의료 진단 |

#### 3. 모델 구성 Best Practice

- **Bad Practice (나쁜 예시)**
  ```python
  # 정규화 없이 학습 → 수렴 불안정
  x_train_raw = x_train  # 0~255 그대로 사용
  model.fit(x_train_raw, y_train, epochs=10)
  ```

- **Good Practice (좋은 예시)**
  ```python
  # 정규화 + validation_split으로 과적합 모니터링
  x_train_norm = x_train / 255.0
  x_test_norm = x_test / 255.0
  history = model.fit(
      x_train_norm, y_train,
      epochs=20,
      batch_size=64,
      validation_split=0.1,   # 훈련 중 검증 손실 확인
      callbacks=[
          tf.keras.callbacks.EarlyStopping(patience=3, restore_best_weights=True)
      ]
  )
  ```

- **설명**: 정규화 없이는 활성화 함수의 포화(saturation) 문제로 학습이 느리거나 수렴에 실패한다. `validation_split`과 `EarlyStopping`을 사용하면 과적합 시점을 자동으로 감지하고 최적 모델을 보존한다.
