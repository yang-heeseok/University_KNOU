# AI를위한수학의응용 연습문제

## 제1장 선형대수학 개요

### 연습문제

1. 다음 중 선형대수학의 핵심 개념으로 볼 수 없는 것은?
   ① 벡터(vector)
   ② 행렬(matrix)
   ③ 선형변환(linear transformation)
   ④ 조건부 확률(conditional probability)

2. 다음 중 인공지능에서 데이터를 벡터 또는 행렬로 표현하는 가장 주된 이유는?
   ① 사람의 직관에 더 적합하기 때문에
   ② 정형 데이터를 그래픽으로 표현하기 위해
   ③ 수치 연산을 효율적으로 수행하기 위해
   ④ 확률 모델을 만들기 위해

3. 다음 중 자연어 처리에서 단어를 수치 벡터로 변환하는 대표적인 기법은?
   ① 워드 임베딩(word embedding)
   ② 주성분분석(Principal Component Analysis, PCA)
   ③ 합성곱(convolution)
   ④ 데이터 증강(data augmentation)

4. 다음 중 행렬이 ‘데이터 변환’의 수학적 도구로 활용되는 대표적인 상황은?
   ① 입력 데이터를 무작위로 섞을 때
   ② 벡터를 회전하거나 축소할 때
   ③ 출력 값을 이산화할 때
   ④ 범주형 데이터를 인코딩할 때

5. 다음 중 고윳값 분해(eigen decomposition) 또는 특이값 분해(SVD)의 주요 목적은?
   ① 예측 결과를 확률로 바꾸는 것
   ② 다층 퍼셉트론의 활성화 함수를 설정하는 것
   ③ 경사하강법의 수렴 속도를 높이기 위한 것
   ④ 데이터의 구조를 요약하고 차원을 축소하는 것

### 연습문제 정답 및 풀이

1. ④ / 조건부 확률은 확률론의 개념이며, 벡터, 행렬, 선형변환, 고윳값은 모두 선형대수학의 핵심 개념이다.

2. ③ / 인공지능 모델은 대부분 벡터와 행렬 연산을 기반으로 작동하므로, 데이터를 이러한 구조로 표현하면 계산 효율성과 병렬 처리가 가능하다.

3. ① / 자연어 처리에서 단어를 수치 벡터로 바꾸는 대표적인 기법은 워드 임베딩이며, 이는 의미 기반의 벡터 표현을 생성하는 데 사용된다.

4. ② / 행렬은 선형변환을 수행하는 수학적 연산자이므로, 벡터를 회전하거나 축소하는 연산은 행렬 곱을 통해 표현된다.

5. ④ / 고윳값 분해와 특이값 분해는 고차원 데이터를 요약하고, 정보 손실을 최소화하면서 차원을 축소하는 데 주로 활용된다.

## 제2장 벡터와 공간

### 연습문제

1. 다음 중 벡터 공간의 정의를 만족하는 조건이 아닌 것은?
   ① 두 벡터의 합도 벡터 공간에 속한다.
   ② 벡터에 0을 곱하면 항상 영벡터가 된다.
   ③ 벡터 공간에는 항상 기준 좌표계가 존재해야 한다.
   ④ 스칼라 곱에 대해 분배 법칙이 성립한다.

2. 다음 벡터들 중 서로 수직인 벡터 쌍을 모두 고르시오.
   ① `(2), (-2)`
   ② `(3), (1)`
   ③ `(3), (1)`
   ④ `(2), (2)`

3. 벡터 `v = (4)`의 L² 노름(`||v||`)을 구하시오.

4. 벡터 `v = (6)`을 정규화한 단위 벡터를 구하시오.

5. 두 벡터 `v = (3), u = (1)`의 내적을 구하고, 그 사잇각 `θ`의 범위를 쓰시오.

6. 벡터 `u = (2)`를 벡터 `v = (3)` 위로 정사영한 벡터를 구하시오.

7. 두 벡터 `v = (1), u = (-1)`의 코사인 유사도를 구하시오.

8. 다음 중 벡터 `v, u, w ∈ Rⁿ`과 스칼라 `s ∈ R`에 대하여, 벡터의 내적에 대한 성질로 옳지 않은 것은?
   ① `v · u = u · v`
   ② `(sv) · u = s (u · v)`
   ③ `v · (u + w) = v · u + v · w`
   ④ `v · (u + w) = u · v + w · u`

9. 다음 중 벡터의 정사영에 대한 설명으로 옳은 것을 모두 고르시오.
   ① 정사영 벡터는 항상 원래 벡터보다 크거나 같다.
   ② 두 벡터가 직각이면 정사영 벡터는 0이다.
   ③ 정사영 벡터는 기준 벡터와 같은 방향을 가진다.
   ④ 사잇각이 90°보다 크면 정사영 벡터의 방향은 기준 벡터와 반대가 된다.

10. 28×28 크기의 흑백 이미지를 벡터로 표현할 경우 벡터의 차원을 구하시오.

11. 다음 중 범주형 데이터를 벡터로 표현하는 방법으로 가장 적절한 것은?
    ① 정규화
    ② 주성분분석
    ③ 원-핫 인코딩
    ④ 코사인 유사도

### 연습문제 정답 및 풀이

1. ③ / 벡터 공간은 연산 성질을 만족하는 집합이며, 기준 좌표계가 반드시 존재할 필요는 없다.

2. ② / 두 벡터가 수직일 경우 내적이 0이다.

3. `||v|| = √4² + 3² = √25 = 5`

4. `v / ||v|| = (6) / √6² + 8² = (6) / √100 = (6) / 10 = (0.6)`

5. `v · u = 2 × 3 + 1 × 4 = 10`
   `cos θ = (v · u) / (||v|| ||u||) = 10 / (√2² + 1² × √3² + 4²) = 10 / (√5 × √25) = 10 / (√5 × 5) = 2 / √5`
   코사인 유사도가 `0 < 2/√5 < 1`이므로 사잇각의 범위는 `0° < θ < 90°`이다.

6. `proj_v u = ((u · v) / ||v||²) v = ((1 × 3 + 2 × 3) / (3² + 3²)) (3) = (9 / 18) (3) = (1/2) (3) = (1.5)`

7. `cos θ = (v · u) / (||v|| ||u||) = (1 × 1 + (-1) × 1) / (√1² + (-1)² × √1² + 1²) = 0 / (√2 × √2) = 0`

8. ④ / `v · (u + w) = v · u + v · w`는 맞지만, `u · v + w · u`는 `v · u + u · w`와 같지 않다.

9. ②, ③, ④ / 정사영 벡터의 크기는 작아질 수 있고, 방향도 반대가 될 수 있다.

10. `28 × 28 = 784`

11. ③ / 범주형 데이터의 벡터화는 원-핫 인코딩이 기본 방식이다.

### 연습문제 정답 및 풀이

1. ② / 전치행렬은 원소의 부호가 아니라 행과 열을 바꾸는 연산이다.

2. ① / 3×2 행렬과 행렬 곱 연산이 가능한 행렬은 행이 2개인 행렬이다.

3. `Aᵀ = `
   ```
   [1 4]
   [2 5]
   [3 6]
   ```

4. `AB = `
   ```
   [1 0]   [2 0 0]   [2 0 0]
   [0 2] * [0 -1 5] = [0 -2 10]
   [4 5]             [8 -5 25]
   ```
   `BA`는 곱셈이 불가능하다. (B는 2x3, A는 3x2이므로 BA는 2x2 행렬이 됨)
   `BA = `
   ```
   [2 0 0]   [1 0]   [2 0]
   [0 -1 5] * [0 2] = [20 23]
             [4 5]
   ```
   `AB ≠ BA`

5. 행렬 `A`의 첫 번째 행(1,0,3)을 기준으로 행렬식을 계산하면
   `det(A) = 1 * det([1 4; -1 0]) - 0 * det([0 4; 5 0]) + 3 * det([0 1; 5 -1])`
   `= 1 * (0 - (-4)) - 0 + 3 * (0 - 5)`
   `= 4 - 15 = -11`

6. ② / `det(A) = ad - bc ≠ 0`일 때 역행렬이 존재한다.

7. `A⁻¹ = (1 / (3*1 - 2*1)) [1 -2; -1 3] = (1 / 1) [1 -2; -1 3] = [1 -2; -1 3]`

8. ④ / 항등변환은 특정 선형변환일 뿐이며, 모든 선형변환이 항등변환은 아니다.

9. 두 열벡터가 서로 선형독립이므로 `rank(A) = 2`

10. 벡터 `v = (1)`에 원점을 중심으로 90° 회전하는 회전행렬 `R_θ`를 곱하면,
    `θ = 90°`, `R_90 = [cos 90° -sin 90°; sin 90° cos 90°] = [0 -1; 1 0]`
    `R_90 v = [0 -1; 1 0] (1) = (-1)`

11. (1) `Ax = b`, `A = [1 1; -1 -1]`, `x = (x; y)`, `b = (2; 5)`
    (2) `rank(A) = rank([1 1; -1 -1]) = 1`
        `rank([A|b]) = rank([1 1 2; -1 -1 5]) = 2`
    (3) `rank(A) ≠ rank([A|b])`이므로 해가 존재하지 않는다(불능).

12. `Ax = b`, `A = [2 1; 1 1]`, `x = (x; y)`, `b = (5; 3)`
    `A⁻¹ = (1 / (2*1 - 1*1)) [1 -1; -1 2] = (1 / 1) [1 -1; -1 2] = [1 -1; -1 2]`
    `x = A⁻¹ b = [1 -1; -1 2] (5; 3) = (5 - 3; -5 + 6) = (2; 1)`

### 연습문제 정답 및 풀이

1. ④ / 확률 벡터는 각 변수의 단위가 달라도 무방하다.

2. ③ / 비대각 성분은 변수 간의 공분산을 나타내며 이를 표준화한 값이 상관계수이다.

3. ③ / 상관계수는 -1과 1 사이의 값을 가지며, 1에 가까울수록 양의 선형 관계가 강하다.

4. ④ / 각 변수가 개별적으로 정규분포를 따른다고 해서 다변량 정규분포가 성립한다는 보장은 없다.

5. ③ / 마할라노비스 거리는 공분산 구조를 반영하여 측정되며 유클리드 거리와 구분되는 다른 개념이다.

6. ① / 등고선의 형태는 타원형이며 중심은 평균 벡터 `μ`이다.

7. ③ / 다변량 정규분포에서 공분산행렬이 양의 정부호일 때만 다변량 정규분포의 확률밀도함수가 유효하게 정의된다.

8. ① / 식 (11.11) 참조
   `Y = AᵀX + b`
   `E[Y] = E[AᵀX + b] = AᵀE[X] + b = Aᵀμ + b`
   `Cov[Y] = Cov[AᵀX + b] = AᵀCov[X]A = AᵀΣA`
   So, `Y ~ N_k(Aᵀμ + b, AᵀΣA)`.

9. ③ / 역행렬이 존재하려면 모든 고윳값이 양수여야 한다(공분산행렬이 양의 정부호여야 한다).

10. ① / 주성분 분석(PCA)은 분석 단계에서 수행되는 기법으로 데이터 수집 비용과는 관련이 없다.

11. ② / 식 (11.10)에 의하면 `X₁|X₂ = x₂ ~ N(μ₁ + (σ₁₂/σ₂²)(x₂ - μ₂), σ₁² - σ₁₂²/σ₂²)`이므로
    `μ₁ = 0, μ₂ = 0, σ₁² = 1, σ₂² = 1, σ₁₂ = 0.4`
    `E[X₁|X₂ = x₂] = 0 + (0.4/1)(x₂ - 0) = 0.4x₂`
    `Var[X₁|X₂ = x₂] = 1 - (0.4²/1) = 1 - 0.16 = 0.84`
    따라서 `X₁|X₂ = x₂ ~ N(0.4x₂, 0.84)`

12. ④ / 공분산이 음수이면 음의 상관관계를 나타낸다.

13. ② / 주성분 분석의 첫 단계는 데이터의 중심화(평균 제거)이다.

14. ③ / 식 (11.20) 참조

15. ③ / 양의 준정부호 행렬은 고윳값이 0이 될 수 있으나 음수는 존재할 수 없다.
