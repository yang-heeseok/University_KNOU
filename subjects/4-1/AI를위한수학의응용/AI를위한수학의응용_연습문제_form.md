#### 📝 문제

**1. 📌 ⭐ [기억] [선형대수학의 핵심 개념으로 볼 수 없는 것은?](#c1-prob-1)**
   > ① 벡터(vector)
   > ② 행렬(matrix)

**2. 📌 ⭐ [이해] [인공지능에서 데이터를 벡터 또는 행렬로 표현하는 가장 주된 이유는?](#c1-prob-2)**
   > ① 사람의 직관에 더 적합하기 때문에
   > ② 정형 데이터를 그래픽으로 표현하기 위해
   > ③ 수치 연산을 효율적으로 수행하기 위해

<br>

**3. 📌 ⭐ [기억/이해] [자연어 처리에서 단어를 수치 벡터로 변환하는 대표적인 기법은?](#c1-prob-3)**

   > ② 주성분분석(Principal Component Analysis, PCA)
   > ③ 합성곱(convolution)
   > ④ 데이터 증강(data augmentation)

<br>

**4. 📌 ⭐⭐ [이해] [행렬이 '데이터 변환'의 수학적 도구로 활용되는 대표적인 상황은?](#c1-prob-4)**
   > ① 입력 데이터를 무작위로 섞을 때
   > ② 벡터를 회전하거나 축소할 때
   > ③ 출력 값을 이산화할 때
   > ④ 범주형 데이터를 인코딩할 때

<br>

**5. 📌 ⭐⭐ [이해] [고윳값 분해(eigen decomposition) 또는 특이값 분해(SVD)의 주요 목적은?](#c1-prob-5)**
   > ① 예측 결과를 확률로 바꾸는 것
   > ② 다층 퍼셉트론의 활성화 함수를 설정하는 것
   > ③ 경사하강법의 수렴 속도를 높이기 위한 것
   > ④ 데이터의 구조를 요약하고 차원을 축소하는 것

> **해설**: 행렬은 선형변환을 수행하는 연산자이므로, 벡터의 회전·축소(스케일링) 같은 변환은 행렬 곱으로 표현된다.

> **해설**: 고윳값 분해(정방행렬)와 특이값 분해(임의 $m\times n$ 행렬)는 고차원 데이터를 요약하고, 정보 손실을 최소화하며 차원을 축소하는 데 주로 활용된다.

### ✅ O/X 확인문제

**1.** 벡터와 행렬 연산은 현대 인공지능 수치 계산의 핵심 기반이다. (#c1-ox-1) **(O / X)**
**2.** 조건부 확률은 선형대수학의 핵심 개념에 속한다. (#c1-ox-2) **(O / X)**
**3.** 데이터를 벡터·행렬로 표현하면 수치 연산을 효율적으로 수행할 수 있다. (#c1-ox-3) **(O / X)**
**4.** 워드 임베딩은 단어를 수치 벡터로 변환하는 대표적인 기법이다. (#c1-ox-4) **(O / X)**
**5.** 주성분분석(PCA)은 단어를 벡터로 바꾸는 대표적인 워드 임베딩 기법이다. (#c1-ox-5) **(O / X)**
**6.** 행렬은 벡터를 회전·축소하는 선형변환 연산자로 활용된다. (#c1-ox-6) **(O / X)**
**7.** 고윳값 분해·특이값 분해의 주요 목적은 예측 결과를 확률로 바꾸는 것이다. (#c1-ox-7) **(O / X)**
**8.** 특이값 분해(SVD)는 임의의 $m\times n$ 행렬에 대해 적용할 수 있다. (#c1-ox-8) **(O / X)**
**9.** 고윳값 분해는 정사각(정방)행렬에 대해 정의되는 분해이다. (#c1-ox-9) **(O / X)**
**10.** 차원 축소는 정보 손실을 최소화하면서 데이터 구조를 요약하는 것을 목표로 한다. (#c1-ox-10) **(O / X)**

<details>
<summary>O/X 정답 및 해설 보기 (클릭)</summary>

> <a id="c1-ox-1"></a>
> **1. 정답: O**
> **해설**: 현대 AI·머신러닝의 수치 계산은 선형대수(벡터·행렬 연산)를 기반으로 한다.

> <a id="c1-ox-2"></a>
> **2. 정답: X**
> **해설**: 조건부 확률은 확률론의 개념이며 선형대수학의 핵심 개념이 아니다.

> <a id="c1-ox-3"></a>
> **3. 정답: O**
> **해설**: 벡터·행렬 표현은 계산 효율과 병렬 처리를 가능하게 한다.

> <a id="c1-ox-4"></a>
> **4. 정답: O**
> **해설**: 워드 임베딩(Word2Vec·GloVe 등)은 단어를 의미 기반 수치 벡터로 바꾸는 대표 기법이다.

> <a id="c1-ox-5"></a>
> **5. 정답: X**
> **해설**: PCA는 차원 축소 기법이다. 단어의 벡터화 대표 기법은 워드 임베딩이다.

> <a id="c1-ox-6"></a>
> **6. 정답: O**
> **해설**: 행렬은 선형변환 연산자로서 벡터의 회전·축소 등을 수행한다.

> <a id="c1-ox-7"></a>
> **7. 정답: X**
> **해설**: 고윳값·특이값 분해의 목적은 데이터 구조 요약과 차원 축소이다. 확률로의 변환과는 무관하다.

> <a id="c1-ox-8"></a>
> **8. 정답: O**
> **해설**: SVD $A=U\Sigma V^\top$ 는 임의의 $m\times n$ 행렬에 항상 존재한다.

> <a id="c1-ox-9"></a>
> **9. 정답: O**
> **해설**: 고윳값 분해는 정방행렬에 한정되며, 대각화가 불가능한 경우도 있다.

> <a id="c1-ox-10"></a>
> **10. 정답: O**
> **해설**: 차원 축소의 목표는 정보 손실을 최소화하면서 데이터의 구조를 요약하는 것이다.

</details>

<summary>해설 보기 (클릭)</summary>

<a id="c2-prob-1"></a>
**1. 📌 ⭐ [기억/이해] 벡터 공간의 정의**
> **정답: ③ 벡터 공간에는 항상 기준 좌표계가 존재해야 한다 (옳지 않음)**
> **해설**: 벡터 공간은 덧셈·스칼라곱의 연산 성질(닫힘·분배법칙 등)을 만족하는 집합으로 정의되며, 특정 기준 좌표계의 존재를 요구하지 않는다.

<a id="c2-prob-2"></a>
**2. 📌 ⭐⭐ [적용] 수직인 벡터 쌍**
> **정답: ② $[1, 1]$, $[1, -1]$**
> **해설**: 두 벡터가 수직이면 내적이 0이다. ②는 $1\cdot1 + 1\cdot(-1) = 0$. 나머지는 ① $-1$, ③ $2$, ④ $5$ 로 0이 아니다.

<a id="c2-prob-3"></a>
**3. 📌 ⭐ [적용] $L^2$ 노름**
> **정답: $\lVert v\rVert = 5$**
> **해설**: $\lVert v\rVert = \sqrt{4^2 + 3^2} = \sqrt{25} = 5$.

<a id="c2-prob-4"></a>
**4. 📌 ⭐⭐ [적용] 단위 벡터(정규화)**
> **정답: $[0.6,\ 0.8]$**
> **해설**: $\dfrac{v}{\lVert v\rVert} = \dfrac{[6,8]}{\sqrt{6^2+8^2}} = \dfrac{[6,8]}{10} = [0.6,\ 0.8]$.

<a id="c2-prob-5"></a>
**5. 📌 ⭐⭐ [적용] 내적과 사잇각 범위**
> **정답: $v\cdot u = 10$, $0° < \theta < 90°$**
> **해설**: $v\cdot u = 2\cdot3 + 1\cdot4 = 10$. $\cos\theta = \dfrac{10}{\sqrt5\cdot5} = \dfrac{2}{\sqrt5} \approx 0.894$ 로 $0 < \cos\theta < 1$ 이므로 사잇각은 $0° < \theta < 90°$.

<a id="c2-prob-6"></a>
**6. 📌 ⭐⭐⭐ [적용] 정사영 벡터**
> **정답: $[1.5,\ 1.5]$**
> **해설**: $\text{proj}_v u = \dfrac{u\cdot v}{\lVert v\rVert^2}v = \dfrac{1\cdot3 + 2\cdot3}{3^2+3^2}[3,3] = \dfrac{9}{18}[3,3] = [1.5,\ 1.5]$.

<a id="c2-prob-7"></a>
**7. 📌 ⭐⭐ [적용] 코사인 유사도**
> **정답: $0$**
> **해설**: $\cos\theta = \dfrac{v\cdot u}{\lVert v\rVert\lVert u\rVert} = \dfrac{1\cdot1 + (-1)\cdot1}{\sqrt2\cdot\sqrt2} = \dfrac{0}{2} = 0$ (두 벡터가 직교).

<a id="c2-prob-8"></a>
**8. 📌 ⭐⭐ [분석] 내적의 성질**
> **정답: ④ $v \cdot (u + w) = u \cdot v + w \cdot u$ (옳지 않음)**
> **해설**: 분배법칙은 $v\cdot(u+w) = v\cdot u + v\cdot w$ 이다. ④의 우변 $u\cdot v + w\cdot u$ 에서 $w\cdot u$ 는 $v\cdot w$ 와 일반적으로 다르므로 등식이 성립하지 않는다. ①(교환)②(스칼라)③(분배)는 모두 옳다.

<a id="c2-prob-9"></a>
**9. 📌 ⭐⭐ [이해] 정사영의 성질**
> **정답: ②, ③, ④**
> **해설**: 정사영 벡터의 크기는 원래 벡터보다 작거나 같으므로 ①은 틀리다. ② 직각이면 정사영은 0, ③ 기준 벡터와 평행, ④ 둔각이면 반대 방향이 되어 모두 옳다.

<a id="c2-prob-10"></a>
**10. 📌 ⭐ [적용] 이미지의 벡터 차원**
> **정답: $784$**
> **해설**: 흑백 이미지의 각 픽셀이 하나의 성분이므로 $28 \times 28 = 784$ 차원이다.

<a id="c2-prob-11"></a>
**11. 📌 ⭐ [기억] 범주형 데이터의 벡터화**

<a id="c3-prob-4"></a>
**4. 📌 ⭐⭐⭐ [적용] 행렬 곱의 비교(비가환)**

> **해설**: $A=\begin{pmatrix}3&1\\0&2\end{pmatrix}$ 의 고윳값은 3, 2. $\lambda=3$ 의 고유벡터는 $[1,0]$(x축), $\lambda=2$ 의 고유벡터는 $[1,-1]$ 방향이다. 두 벡터는 직교하지 않고(① 틀림) 선형독립이다(④ 틀림).

> **해설**: $\det(A-\lambda I)=0$ 은 고윳값 $\lambda$ 를 구하는 특성방정식이다.

<a id="c4-prob-4"></a>

<a id="c4-prob-5"></a>
**5. 📌 ⭐⭐ [이해] 대각화 가능 조건**

> **해설**: $A^\top A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 의 고윳값 $3,1$ → 특이값 $\sqrt3,1$. 우특이벡터 $v_1=[1,1]/\sqrt2,\ v_2=[1,-1]/\sqrt2$. 좌특이벡터는 $u_i=A v_i/\sigma_i$ 로 계산: $u_1=[2,1,1]/\sqrt6,\ u_2=[0,1,-1]/\sqrt2$.

> **해설**: SVD로부터 무어-펜로즈 유사역행렬은 $A^+=V\Sigma^+U^\top$ 로 정의된다($\Sigma^+$ 는 0이 아닌 특이값의 역수를 취해 전치). ②는 $A$ 가 full column rank일 때만 성립하는 특수식이다.

<a id="c5-prob-8"></a>
**8. 📌 ⭐⭐ [분석] SVD 기하 해석**
> **정답: ② 좌특이벡터는 $A^\top A$의 고유벡터이다 (옳지 않음)**
> **해설**: 좌특이벡터는 $AA^\top$ 의 고유벡터이고, **우**특이벡터가 $A^\top A$ 의 고유벡터이다. ①③④는 옳은 해석이다.

<a id="c5-prob-9"></a>
**9. 📌 ⭐⭐⭐ [적용] 유사역행렬 계산**
> **정답: $A^+ = \dfrac{1}{3}\begin{pmatrix} 1 & 2 & -1 \\ 1 & -1 & 2 \end{pmatrix}$**

## 제6장 선형회귀와 최소제곱법

### ❓ 연습 문제 및 해설

#### 📝 문제

**1. 📌 ⭐ [기억/이해] [선형회귀모형 $y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$에서 $\beta_1$의 의미로 옳은 것은?](#c6-prob-1)**
   > ① 설명변수 $x_1$이 1단위 증가할 때, 종속변수 $y$의 기댓값이 $\beta_1$만큼 증가한다.
   > ② $x_1$과 $y$ 사이의 상관계수를 나타낸다.
   > ③ $y$의 분산을 설명하는 비율이다.
   > ④ 절편 회귀계수이다.

<br>

**2. 📌 ⭐ [기억] [선형회귀모형을 행렬로 올바르게 표현한 것은?](#c6-prob-2)**
   > ① $\mathbf{y} = X + \boldsymbol\beta + \boldsymbol\varepsilon$
   > ② $\mathbf{y} = X\boldsymbol\beta + \boldsymbol\varepsilon$
   > ③ $\mathbf{y} = \boldsymbol\beta X + \boldsymbol\varepsilon$
   > ④ $\mathbf{y} = X^\top\boldsymbol\beta + \boldsymbol\varepsilon$

<br>

**3. 📌 ⭐⭐ [이해] [오차(error)와 잔차(residual)의 차이에 대한 설명으로 옳은 것은?](#c6-prob-3)**
   > ① 오차는 계산할 수 있으나 잔차는 알 수 없다.
   > ② 잔차는 이론적으로 정의되며 오차는 추정치이다.
   > ③ 오차는 회귀계수의 참값을 알 때 정의되며, 잔차는 추정된 회귀계수로 계산된다.
   > ④ 오차와 잔차는 동일한 개념이므로 구분할 필요가 없다.

<br>

**4. 📌 ⭐ [기억/이해] [최소제곱법에서 최소화하는 잔차제곱합(RSS)의 정의로 옳은 것은?](#c6-prob-4)**
   > ① $RSS = \sum(y_i - \bar{y})^2$
   > ② $RSS = \sum(y_i - \hat{y}_i)^2$
   > ③ $RSS = \sum(x_i - \bar{x})^2$
   > ④ $RSS = \sum \hat{y}_i^2$

<br>

**5. 📌 ⭐ [기억] [정규방정식(normal equation)의 형태로 올바른 것은?](#c6-prob-5)**
   > ① $X\mathbf{y} = X^\top X\boldsymbol\beta$
   > ② $\mathbf{y} = X\boldsymbol\beta$
   > ③ $XX^\top\boldsymbol\beta = \mathbf{y}$
   > ④ $X^\top X\boldsymbol\beta = X^\top \mathbf{y}$

<a id="c6-prob-1"></a>
**1. 📌 ⭐ [기억/이해] 회귀계수의 의미**
> **정답: ① 설명변수가 1단위 증가할 때 $y$의 기댓값이 $\beta_1$만큼 증가한다**
> **해설**: 기울기 $\beta_1$ 은 설명변수 1단위 변화당 종속변수 평균(기댓값)의 변화량이다.

<a id="c6-prob-2"></a>
**2. 📌 ⭐ [기억] 회귀모형의 행렬 표현**
> **정답: ② $\mathbf{y} = X\boldsymbol\beta + \boldsymbol\varepsilon$**
> **해설**: 설계행렬 $X$, 계수벡터 $\boldsymbol\beta$, 오차 $\boldsymbol\varepsilon$ 으로 $\mathbf{y}=X\boldsymbol\beta+\boldsymbol\varepsilon$ 이다.

<a id="c6-prob-3"></a>
**3. 📌 ⭐⭐ [이해] 오차와 잔차**
> **정답: ③ 오차는 참값을 알 때 정의되고, 잔차는 추정값으로 계산된다**
> **해설**: 오차 $\varepsilon_i = y_i - (\beta_0+\beta_1 x_i)$ 는 참 계수 기준(관측 불가), 잔차 $e_i = y_i - \hat{y}_i$ 는 추정 계수 기준(계산 가능)이다.

<a id="c6-prob-4"></a>
**4. 📌 ⭐ [기억/이해] 잔차제곱합(RSS)**
> **정답: ② $RSS = \sum(y_i - \hat{y}_i)^2$**
> **해설**: RSS는 관측값과 예측값 차이(잔차)의 제곱합이다. ①은 총변동(SST), ③은 $x$ 의 변동이다.

<a id="c6-prob-5"></a>
**5. 📌 ⭐ [기억] 정규방정식**
> **정답: ④ $X^\top X\boldsymbol\beta = X^\top \mathbf{y}$**
> **해설**: RSS를 $\boldsymbol\beta$ 로 미분해 0으로 두면 정규방정식 $X^\top X\boldsymbol\beta = X^\top\mathbf{y}$ 가 나온다.

<a id="c6-prob-6"></a>
**6. 📌 ⭐⭐⭐ [적용] 정규방정식 풀이**
> **정답: $\hat{\boldsymbol\beta} = [1/3,\ 3/2]^\top$**
> **해설**: $X=\begin{pmatrix}1&1\\1&2\\1&3\end{pmatrix}$, $X^\top X=\begin{pmatrix}3&6\\6&14\end{pmatrix}$, $(X^\top X)^{-1}=\begin{pmatrix}7/3&-1\\-1&1/2\end{pmatrix}$, $X^\top\mathbf{y}=[10,23]^\top$. $\hat{\boldsymbol\beta}=(X^\top X)^{-1}X^\top\mathbf{y} = [70/3-23,\ -10+23/2]^\top = [1/3,\ 3/2]^\top$.

<a id="c6-prob-7"></a>
**7. 📌 ⭐⭐ [이해] 정규방정식의 한계**
> **정답: ④ 모든 경우에 항상 계산이 안정적이고 빠르다 (옳지 않음)**
> **해설**: 정규방정식은 변수 수가 많거나 다중공선성이 있을 때 불안정하고, $X^\top X$ 역행렬 계산 비용이 커 대규모·스트리밍 데이터에 불리하다. ①②③은 실제 한계이다.

<a id="c6-prob-8"></a>
**8. 📌 ⭐ [기억] 경사하강법 갱신식**
> **정답: ② $\beta^{(t+1)} = \beta^{(t)} - \eta \nabla f(\beta^{(t)})$**
> **해설**: 손실의 기울기(gradient) $\nabla f$ 반대 방향으로 학습률 $\eta$ 만큼 이동한다.

<a id="c6-prob-9"></a>
**9. 📌 ⭐ [이해] 학습률**
> **정답: ① 학습률은 매 반복의 이동 보폭 크기를 조절한다**
> **해설**: 학습률은 보폭(스텝 크기)을 조절한다. 방향은 기울기가 정하며(③ 틀림), 너무 크면 발산(④ 틀림), 너무 작으면 수렴이 느리다(②는 작을 때 발산이라 틀림).

<a id="c6-prob-10"></a>
**10. 📌 ⭐⭐ [이해] 정규방정식 vs 경사하강법**
> **정답: ③ 정규방정식은 닫힌 해를, 경사하강법은 반복적 해를 준다**
> **해설**: 둘 다 같은 최소제곱 문제를 풀되, 정규방정식은 해석적 닫힌 해, 경사하강법은 수치적 반복 수렴 방식이다.

> **정답: $A = \begin{pmatrix}0&1&1\\1&0&1\\1&1&0\end{pmatrix},\ D = \begin{pmatrix}2&0&0\\0&2&0\\0&0&2\end{pmatrix},\ L = D-A = \begin{pmatrix}2&-1&-1\\-1&2&-1\\-1&-1&2\end{pmatrix}$**
> **해설**: 삼각형은 모든 노드가 서로 연결돼 인접행렬 비대각이 1, 각 노드 차수 2, $L=D-A$.

<a id="c7-prob-6"></a>
**6. 📌 ⭐ [기억/이해] 은닉층 연산**
> **정답: ① $a^{(l)} = \varphi(W^{(l)}a^{(l-1)} + b^{(l)})$**
> **해설**: 선형변환 $z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)}$ 후 활성화 $a^{(l)}=\varphi(z^{(l)})$ 를 적용한다.

<a id="c7-prob-7"></a>
**7. 📌 ⭐⭐ [적용] 선형 연산**
> **정답: $z = [-1,\ 3]$**
> **해설**: $Wx = [1\cdot1+(-1)\cdot2,\ 2\cdot1+0\cdot2] = [-1, 2]$. $z = [-1,2]+[0,1] = [-1, 3]$.

<a id="c7-prob-8"></a>
**8. 📌 ⭐ [적용] ReLU**
> **정답: $[1,\ 0]$**
> **해설**: $\text{ReLU}(x)=\max(0,x)$ 이므로 $[1, -1] \to [1, 0]$.

<a id="c7-prob-9"></a>
**9. 📌 ⭐⭐ [적용/분석] 시그모이드의 치역**
> **정답: ② 모든 성분이 0과 1 사이에 있다**
> **해설**: $\sigma(-3)\approx0.05,\ \sigma(2)\approx0.88,\ \sigma(0)=0.5$ 로 모두 $(0,1)$ 안에 있다. 시그모이드의 치역이 $(0,1)$ 이기 때문이다.

<a id="c7-prob-10"></a>
**10. 📌 ⭐⭐ [적용] 은닉층 + ReLU**
> **정답: $[2,\ 2]$**
> **해설**: $Wx+b = [2\cdot1+0\cdot1,\ 1\cdot1+1\cdot1]+[0,0] = [2, 2]$. ReLU 적용해도 양수라 $[2, 2]$.

<a id="c7-prob-11"></a>
**11. 📌 ⭐ [기억/이해] 활성화 함수의 목적**
> **정답: ④ 비선형성을 도입하여 복잡한 패턴을 표현하기 위해서**
> **해설**: 활성화 함수가 없으면 층을 쌓아도 전체가 하나의 선형변환이 된다. 비선형성 도입이 핵심 역할이다.

</details>

<summary>해설 보기 (클릭)</summary>

<a id="c8-prob-1"></a>
**1. 📌 ⭐ [적용] 표본공간의 크기**
> **정답: $8$**
> **해설**: 각 동전이 앞/뒤 2가지이므로 $2^3 = 8$.

<a id="c8-prob-2"></a>
**2. 📌 ⭐ [기억/이해] 독립의 정의**
> **정답: ② $P(A \cap B) = P(A) \times P(B)$**
> **해설**: 독립이면 $P(A\cap B)=P(A)P(B)$, $P(A|B)=P(A)$ 가 성립한다.

<a id="c8-prob-3"></a>
**3. 📌 ⭐ [기억/이해] PMF의 조건**
> **정답: ④ $\sum p(x) = 1$**
> **해설**: 이산형 확률질량함수는 모든 값의 확률 합이 1이어야 한다. 적분(②)은 연속형 조건이다.

<a id="c8-prob-4"></a>
**4. 📌 ⭐ [기억/이해] PDF의 조건**
> **정답: ② $\int_{-\infty}^{\infty} f(x)\,dx = 1$**
> **해설**: PDF는 $f(x)\ge0$ 이며 전체 적분이 1이다. 연속형에서 한 점의 확률은 0이므로 ④는 틀리다.

<a id="c8-prob-5"></a>
**5. 📌 ⭐⭐⭐ [적용] 조건부 확률**
> **정답: $1/6$**
> **해설**: $B$ 의 경우의 수 $4\times6=24$. 그 중 합이 7인 경우 $(1,6),(2,5),(3,4),(4,3)$ 4가지. $P(A|B)=4/24=1/6$.

<a id="c8-prob-6"></a>
**6. 📌 ⭐⭐ [적용] 독립 판정**
> **정답: ③ 서로 독립이다**
> **해설**: $P(A\cap B)=1/4 = (1/2)(1/2)=P(A)P(B)$ 이므로 독립이다.

<a id="c8-prob-7"></a>
**7. 📌 ⭐⭐⭐ [적용] 전확률 정리(베이즈 분모)**
> **정답: $0.068$**
> **해설**: $P(\text{양성}) = 0.98\times0.05 + 0.02\times0.95 = 0.049 + 0.019 = 0.068$.

<a id="c8-prob-8"></a>
**8. 📌 ⭐⭐⭐ [적용] 선형변환의 기댓값·분산**
> **정답: $E[Y]=7.6,\ \text{Var}[Y]=2.44$**
> **해설**: $E[X]=1(0.2)+2(0.3)+3(0.5)=2.3$, $E[X^2]=0.2+1.2+4.5=5.9$, $\text{Var}[X]=5.9-2.3^2=0.61$. $E[2X+3]=2(2.3)+3=7.6$, $\text{Var}[2X+3]=2^2(0.61)=2.44$.

<a id="c8-prob-9"></a>
**9. 📌 ⭐⭐ [적용] 비복원 추출**
> **정답: $2/15 \approx 0.1333$**
> **해설**: $\dfrac{4}{10}\times\dfrac{3}{9}=\dfrac{12}{90}=\dfrac{2}{15}$. (또는 $\binom{4}{2}/\binom{10}{2}=6/45=2/15$.)

<a id="c8-prob-10"></a>
**10. 📌 ⭐⭐⭐ [적용/분석] 삼각분포 CDF와 구간확률**
> **정답: $P(0.5\le Y\le1.5)=0.75$**
> **해설**: $F(y)=\tfrac12 y^2\ (0\le y\le1)$, $F(y)=-1+2y-\tfrac12 y^2\ (1<y\le2)$. $F(1.5)=-1+3-1.125=0.875$, $F(0.5)=0.125$. 차 $=0.875-0.125=0.75$.

> **정답: ④ (옳지 않음)**
> **해설**: 표본평균의 *주변* 분산은 $\tau^2 + \sigma^2/n_i$ 로, 조건부 분산 $\sigma^2/n_i$ 과 다르다($M_i$ 의 변동 $\tau^2$ 이 추가됨).

> **해설**: $\chi^2(1)+\chi^2(1)=\chi^2(2)=Gamma(1,1/2)$ (이는 $Exp(1/2)$ 와도 동일). 보기 중 정확한 표현은 ②.

> **해설**: 독립 카이제곱(각 자유도로 나눈)의 비가 $F$분포의 정의 → $F(1,1)$.
