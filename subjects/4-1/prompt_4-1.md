## 작업 규칙

### 기본 원칙
- **[form.md](subjects\4-1\form_4-1.md) 스타일 엄수**. 분량이 많으면 1개 섹션씩 순차 생성/수정
- **학습목표·요약은 원본 텍스트 그대로** 유지 (포맷만 form.md에 맞춤)
- 수식은 LaTeX 필수 ($인라인$, $$블록$$), 코드는 실행 가능한 Python
- 이미지 입력 시: 텍스트 추출 → form.md 스타일로 재구성, 정답/해설 정확히 보존
- 이미지에 없는 내용은 **추론하지 말고** 해당 강의의 맥락에서 보충

### 섹션별 작성 기준

| 섹션 | 핵심 규칙 |
| :--- | :--- |
| **선수 지식** | 이전 강의 파일 직접 링크, 체크리스트 형태 |
| **학습 목표** | 원본 그대로 유지 |
| **요약 (Summary)** | 원본 유지 + 각 항목에 🔴🟡🟢 출제 가능성 태그 부여 |
| **핵심 수식/정의** | 수식 테이블 + 직관적 해석 + AI 적용 (과목 유형에 따라 변형, 아래 참고) |
| **개념 시각화** | Mermaid 관계도 (개념 3개 이상일 때) + 핵심 비교표 |
| **심화 학습** | 가상 시나리오 + 오개념 분석 (혼동 쌍 명시) + AI 학습 포인트 |
| **연습 문제** | 난이도 ⭐~⭐⭐⭐, 학습 내용 **전체 커버** 되도록 문항수 조절. 원본 우선, 추가분은 📌 표시 |
| **O/X 확인문제** | 연습문항의 **2배** 권장 |
| **코드로 확인** | 실행 가능한 Python + 실행 결과 + 해석 |
| **AI 연결고리** | 학습 개념 → AI/ML 적용 분야 → 구체적 사례 매핑 |
| **심화 학습 예시 답안** | 동작 원리 / 비교표 (AI 활용 행 포함) / Best Practice 코드 |
| **용어집** | 4열: 용어(한) / 용어(영) / 수식 표현 / 정의. 재등장 용어는 `→←N강` 크로스 레퍼런스 |
| **AI 학습 프롬프트** | 개념 이해 / 시나리오 / 수식 풀이 검증 3종 |
| **복습 체크** | 작업 당일 기준 1/3/7/14/30일 후 날짜 자동 계산 (이미 있으면 유지) |

### 과목 유형별 적응

과목 내용에 따라 자동 판단하여 아래 규칙을 적용한다.

| 유형 | 핵심 수식 섹션 변형 | 코드 | 시각화 |
| :--- | :--- | :--- | :--- |
| **수학 중심** (선형대수, 확률통계) | 그대로 (수식 테이블 + 정리 블록) | NumPy/SciPy 검증 | 보통 |
| **이론 중심** (데이터마이닝, 경영학) | → **핵심 정의 및 원리** 테이블로 대체 (정의명 / 내용 / 키워드) | sklearn 개념 시연 | **Mermaid 분류 체계도 필수** |
| **실습 중심** (프로그래밍, DB) | → **핵심 문법 및 패턴** 테이블로 대체 (패턴명 / 코드 / 용도) | 실행 가능 전체 코드 | 보통 |

### 시험 대비 전략
- 요약의 🔴🟡🟢 태그로 암기 우선순위 시각화
- 심화학습에서 혼동 쌍 명시 정리 (예: "지도학습 vs 자율학습"), 오답 함정 패턴을 해설에서 분석
- `기출/` 폴더 존재 시: 관련 문제를 `📎 기출(YYYY-유형)` 태그로 연습문제에 포함, 반복 출제 개념은 🔴 자동 승격
