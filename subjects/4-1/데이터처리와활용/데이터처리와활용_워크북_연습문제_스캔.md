# 데이터 처리와 활용 워크북 연습문제

## 제1장 데이터와 데이터베이스의 이해

### 연습문제

1.  데이터(Data)의 어원인 라틴어 ‘datum'의 의미로 가장 적절한 것은?
    1.  처리된 정보
    2.  주어진 것
    3.  숨겨진 패턴
    4.  의미 있는 결과

    **정답: ②**
    **해설:** 데이터(Data)의 어원인 라틴어 ‘datum'은 '선물' 또는 '주어진 것'을 뜻해, 가공 전의 '주어진 사실'이라는 본질을 드러낸다.

2.  다음 중 데이터의 핵심 특성이 아닌 것은?
    1.  객관성
    2.  맥락의존성
    3.  주관적 해석
    4.  축적 가능성

    **정답: ③**
    **해설:** 데이터의 핵심 특성은 객관성, 맥락의존성, 시간민감성, 축적 가능성이며, ‘주관적 해석'은 객관성에 반하므로 포함되지 않는다.

3.  DIKW 피라미드 모델에서 ‘어떻게(How), 왜(Why)'라는 질문에 답하는 단계는?
    1.  데이터(Data)
    2.  정보(Information)
    3.  지식(Knowledge)
    4.  지혜(Wisdom)

    **정답: ③**
    **해설:** DIKW에서 지식(Knowledge) 단계가 ‘어떻게(How), 왜(Why)'에 답하며, 예측·판단의 근거가 된다.

4.  다음 데이터 중 반정형 데이터(semi-structured data)에 해당하는 것은?
    1.  Excel 스프레드시트의 매출 데이터
    2.  JSON 형식의 API 응답 데이터
    3.  CCTV 영상 파일
    4.  관계형 데이터베이스의 고객 테이블

    **정답: ②**
    **해설:** 반정형 데이터는 태그나 마크업 등으로 어느 정도 체계를 갖춘 자기기술적 데이터이고, 대표 형식에 JSON이 포함된다. 따라서 JSON 형식의 API 응답이 반정형에 해당한다.

5.  정형 데이터의 특징으로 옳지 않은 것은?
    1.  행과 열로 구성된 테이블 형태
    2.  SQL로 쉽게 검색 및 분석 가능
    3.  전체 데이터의 약 80%를 차지
    4.  고정된 스키마(Schema) 존재

    **정답: ③**
    **해설:** 정형 데이터는 전체의 약 20% 수준으로 추정되며(나머지는 비정형 등), '80%를 차지'는 사실과 반대이다.

6.  다음 중 정량적 데이터의 하위 분류가 올바르게 연결된 것은?
    1.  학생 수 - 연속형 데이터
    2.  온도 - 이산형 데이터
    3.  키(height) - 연속형 데이터
    4.  시간 - 명목형 데이터

    **정답: ③**
    **해설:** 키(height)와 같은 값은 무한히 쪼갤 수 있는 연속형(continuous) 정량적 데이터의 전형적 예시이다(예: 키 175.3cm).

7.  데이터 품질의 5대 핵심 요소에 포함되지 않는 것은?
    1.  정확성(accuracy)
    2.  복잡성(complexity)
    3.  일관성(consistency)
    4.  적시성(timeliness)

    **정답: ②**
    **해설:** 데이터 품질의 5대 요소는 정확성·완전성·일관성·적시성·유효성이며, 복잡성은 포함되지 않는다.

8.  다음 상황이 나타내는 데이터 품질 문제는?
    > "고객 데이터베이스에서 필수 항목인 전화번호가 전체 레코드의 30%에서 누락되어 있다."
    1.  정확성 부족
    2.  완전성 부족
    3.  일관성 부족
    4.  유효성 부족

    **정답: ②**
    **해설:** 필수 항목(전화번호) 누락은 필요한 데이터가 빠진 완전성(completeness) 부족 사례이다.

9.  다음 예시가 설명하는 데이터에서 정보로의 변환 과정으로 가장 적절한 것은?
    > ‘42, 서울, 2024-03-15, 35,000' → “김영희 씨(42세)가 2024년 3월 15일 서울에서 35,000원의 도서를 구매했다”
    1.  데이터에 경험을 더해 지식으로 변환
    2.  데이터를 분석하여 패턴을 발견
    3.  데이터에 맥락을 부여하여 의미를 생성
    4.  데이터를 축적하여 지혜로 발전

    **정답: ③**
    **해설:** '42, 서울, 2024-03-15, 35,000'같은 값에 사람·시간·장소·행위의 맥락을 부여해 “김영희 씨(42세)가… 구매했다”라는 정보로 변환한 사례이다.

10. 다음 중 비정형 데이터의 처리 방법으로 적절하지 않은 것은?
    1.  텍스트 데이터 - 자연어 처리(NLP)
    2.  이미지 데이터 - 컴퓨터 비전(Computer Vision)
    3.  음성 데이터 - 음성 인식(Speech Recognition)
    4.  동영상 데이터 - SQL 쿼리

    **정답: ④**
    **해설:** 동영상은 비정형 데이터로 전처리ㆍ전용 기법(시각분석)이 요구되며, SQL 쿼리는 주로 정형 데이터 테이블 질의에 쓰인다. 따라서 ‘동영상 - SQL 쿼리'는 부적절하다.

## 제2장 관계형 데이터 모델

### 연습문제

1.  다음 중 파일 시스템 대비 데이터베이스의 장점으로 보기 어려운 것은?
    1.  데이터 중복 최소화
    2.  세밀한 권한 통제
    3.  자동 백업 및 복구
    4.  파일 간 수동 동기화

    **정답: ④**
    **해설:** 파일 간 수동 동기화는 파일 시스템의 문제점이다. 데이터베이스는 자동으로 데이터 일관성을 유지한다.

2.  테이블의 '행 - 열'을 관계형 용어로 바르게 짝지은 것은?
    1.  행 - 필드, 열 - 레코드
    2.  행 - 속성, 열 - 튜플
    3.  행 - 튜플, 열 - 속성
    4.  행 - 레코드, 열 - 엔티티

    **정답: ③**
    **해설:** 행은 튜플(tuple) 또는 레코드, 열은 속성(attribute) 또는 필드라고 한다.

3.  개체 무결성과 참조 무결성의 연결이 올바른 것은?
    1.  개체 무결성 - 외래키는 중복 불가
    2.  개체 무결성 - 기본키는 NULL 불가
    3.  참조 무결성 - 기본키는 반드시 존재
    4.  참조 무결성 - 기본키는 고유해야 함

    **정답: ②**
    **해설:** 개체 무결성은 기본키가 NULL이 될 수 없고, 중복될 수 없다는 규칙이다. 참조 무결성은 외래키가 참조 테이블의 기본키값이어야 한다는 규칙이다.

4.  학생(학번, 이름, 학과)과 학과(학과코드, 학과명) 테이블이 있을 때, 학생의 학과 속성이 학과의 학과코드 속성을 참조한다. 학과:학생의 관계 유형과 외래키 위치의 올바른 조합은?
    1.  1:1, 학과에 외래키
    2.  1:N, 학과에 외래키
    3.  1:N, 학생에 외래키
    4.  M:N, 연결 테이블 필요

    **정답: ③**
    **해설:** 한 학과에 여러 학생이 속하므로 1:N 관계이며, N쪽인 학생 테이블에 외래키를 둔다.

5.  다대다(M:N) 관계를 구현하기 위한 일반적인 방법은?
    1.  두 테이블에 서로의 기본키를 모두 추가한다.
    2.  한쪽 테이블에 UNIQUE 외래키를 둔다.
    3.  연결(조인) 테이블을 만들어 양쪽을 외래키로 참조한다.
    4.  트리거로 양방향 삽입을 강제한다.

    **정답: ③**
    **해설:** M:N 관계는 연결 테이블(junction table)을 생성하여 양쪽 테이블의 기본키를 외래키로 참조한다.

6.  다음 설명과 가장 가까운 이상(anomaly)은?
    > “수강생이 없는 새 과목을 기록하려면 학생번호를 임시로 채워야 해서 입력이 곤란하다.”
    1.  갱신이상
    2.  삽입이상
    3.  삭제이상
    4.  도메인 이상

    **정답: ②**
    **해설:** 원하는 정보(과목)를 입력하기 위해 불필요한 정보(학생)를 함께 입력해야 하는 문제는 삽입이상이다.

7.  복합키(학생번호, 과목코드)를 가진 테이블에서 ‘학생이름’이 학생번호에만 의존한다면, 위배되는 정규형은?
    1.  1NF
    2.  2NF
    3.  3NF
    4.  BCNF

    **정답: ②**
    **해설:** 복합키의 일부(학생번호)에만 종속되는 부분함수 종속이 존재하므로 2NF를 위배한다.

8.  다음 중 이행적 함수 종속을 제거해 3NF로 나누는 올바른 전략은?
    1.  결정자(중간 속성)를 기본키로 하는 별도 테이블을 분리한다.
    2.  결정자를 제거하고 남은 속성만 둔다.
    3.  모든 속성을 하나의 테이블로 합친다.
    4.  인덱스만 추가한다.

    **정답: ①**
    **해설:** 이행적 종속(A → B → C)에서 중간 결정자 B를 기본키로 하는 별도 테이블(B, C)을 만들어 분리한다.

9.  ER 다이어그램을 테이블로 변환하는 규칙으로 옳은 것은?
    1.  1:N 관계는 1쪽에 외래키 추가
    2.  1:1 관계는 항상 연결 테이블 생성
    3.  M:N 관계는 연결 테이블로 변환
    4.  관계는 모두 뷰로 변환

    **정답: ③**
    **해설:** M:N 관계는 연결 테이블로 변환하고, 1:N은 N쪽에 외래키를 추가한다.

10. 다음 중 ‘도메인 무결성'의 예로 적절한 것은?
    1.  학번은 중복 불가
    2.  외래키는 참조 테이블의 기본키여야 함
    3.  학년 값은 1~4 사이의 정수
    4.  기본키는 NULL 불가

    **정답: ③**
    **해설:** 도메인 무결성은 속성값이 정의된 범위 내에 있어야 한다는 제약이다. 학년이 1~4 사이여야 한다는 것이 대표적 예시이다.

## 제3장 SQLite와 DB 브라우저 실습

### 연습문제

1.  SQLite의 가장 큰 특징으로 적절한 것은?
    1.  대규모 서버 클러스터 환경 전용이다.
    2.  모든 데이터를 하나의 파일에 저장한다.
    3.  설치 과정이 복잡하고 설정이 많다.
    4.  인터넷 연결이 필수이다.

    **정답: ②**
    **해설:** SQLite는 서버 없이 동작하며, 모든 데이터를 단일 파일에 저장하는 구조를 가진다. 이로 인해 설치와 배포가 간편하고, 휴대성이 높다.

2.  DB Browser(SQLite)의 주요 장점이 아닌 것은?
    1.  직관적인 GUI를 제공한다.
    2.  다양한 운영체제를 지원한다.
    3.  상업적 사용이 가능하다.
    4.  SQL 문법을 지원하지 않는다.

    **정답: ④**
    **해설:** DB Browser는 SQL 문법을 지원하며, 오히려 SQL을 직접 작성하고 실행할 수 있는 기능도 제공한다.

3.  DB Browser for SQLite를 설치하기 전에 운영체제 정보를 확인하는 주된 이유는 무엇인가?
    1.  시스템 속도를 향상시키기 위해서이다.
    2.  운영체제와 버전에 맞는 설치 파일을 선택하기 위해서이다.
    3.  설치 과정에서 네트워크 설정을 변경하기 위해서이다.
    4.  데이터베이스 파일 형식을 변환하기 위해서이다.

    **정답: ②**
    **해설:** DB Browser 설치 파일은 운영체제 종류와 버전(32bit/64bit)에 따라 다르므로, 알맞은 설치 파일을 선택해야 정상 동작한다.

4.  SQLite에서 테이블을 생성할 때 필요한 요소가 아닌 것은?
    1.  테이블 이름
    2.  열 이름과 자료형
    3.  기본키 설정 여부
    4.  네트워크 IP 주소

    **정답: ④**
    **해설:** SQLite 테이블 생성에는 네트워크 설정이 필요 없다. IP 주소는 서버형 DB에서나 고려하는 항목이다.

5.  다음 중 SQL 명령어로 테이블의 모든 데이터를 조회하는 것은?
    1.  `SHOW * FROM 테이블명;`
    2.  `SELECT * FROM 테이블명;`
    3.  `VIEW * 테이블명;`
    4.  `LIST ALL 테이블명;`

    **정답: ②**
    **해설:** 'SELECT * FROM 테이블명;'은 테이블의 모든 행과 열을 조회하는 표준 SQL 문법이다. 다른 보기들은 SQL 표준 구문이 아니다.

6.  DB Browser에서 CSV 파일을 불러올 때, 첫 행을 열 이름으로 지정하려면 어떻게 해야 하는가?
    1.  파일 이름을 열 이름과 동일하게 한다.
    2.  ‘첫 행에 필드명 포함' 옵션을 체크한다.
    3.  CSV 파일 확장자를 .db로 변경한다.
    4.  가져오기 전에 SQL로 열 이름을 추가한다.

    **정답: ②**
    **해설:** '첫 행에 필드명 포함' 옵션을 체크하면, CSV 파일의 첫 행을 자동으로 열 이름으로 인식한다. 이는 불필요한 수작업을 줄여 준다.

7.  다음 중 CSV 파일 형식에 대한 설명으로 옳은 것은?
    1.  데이터 항목을 쉼표로 구분하는 텍스트 파일이다.
    2.  오직 엑셀 프로그램에서만 열 수 있다.
    3.  이미지 데이터를 저장하는 전용 형식이다.
    4.  운영체제별로 호환되지 않는다.

    **정답: ①**
    **해설:** CSV는 쉼표(,)로 구분된 데이터가 저장된 텍스트 파일이며, 다양한 프로그램과 운영체제에서 호환된다.

8.  Student 테이블에 ID 1, 이름 ‘홍길동', 나이 50을 추가하는 SQL문으로 알맞은 것은?
    1.  `ADD Student (1, ‘홍길동', 50);`
    2.  `INSERT Student (1, '홍길동', 50);`
    3.  `INSERT INTO Student VALUES (1, ‘홍길동', 50);`
    4.  `ADD INTO Student VALUES (1, ‘홍길동', 50);`

    **정답: ③**

9.  DB Browser에서 기존 데이터베이스를 다시 열려면 어떻게 해야 하는가?

## 제4장 SQL 기초 I: SELECT문

### 연습문제

1.  SQL에서 특정 조건에 맞는 데이터만 추출할 때 사용하는 절은?
    1.  FROM
    2.  WHERE
    3.  ORDER BY
    4.  LIMIT

    **정답: ②**
    **해설:** WHERE절은 행 단위 조건을 지정해 원하는 데이터만 추출한다. 예를 들어, `WHERE Age > 20`은 나이가 20을 초과하는 행만 가져온다.

2.  다음 중 SQL에서 두 조건이 모두 참일 때만 결과를 반환하도록 하는 연산자는?
    1.  OR
    2.  NOT
    3.  AND
    4.  LIKE

    **정답: ③**
    **해설:** AND는 모든 조건이 참일 때만 결과를 반환한다. 반면에, OR는 하나라도 참이면 결과를 반환한다.

3.  다음 SQL문이 의미하는 것은 무엇인가?
    ```sql
    SELECT * FROM Student
    WHERE Age BETWEEN 20 AND 30;
    ```
    1.  나이가 정확히 20세 또는 30세인 학생만 조회한다.
    2.  나이가 20세 이상, 30세 이하인 학생을 조회한다.
    3.  나이가 20세 미만 또는 30세 초과인 학생을 조회한다.
    4.  나이가 25세인 학생만 조회한다.

    **정답: ②**
    **해설:** `BETWEEN A AND B`는 A 이상, B 이하를 포함한다. 즉, 20세와 30세도 결과에 포함된다.

4.  문자열 검색을 위한 SQL 연산자로, `%`와 `_` 와일드카드를 사용하는 것은?
    1.  LIKE
    2.  IN
    3.  NOT
    4.  BETWEEN

    **정답: ①**
    **해설:** LIKE는 특정 패턴을 가진 문자열을 찾는다. 예를 들어, `LIKE ‘김%’`는 '김'으로 시작하는 이름을 찾는다.

5.  다음 중 이름이 ‘홍길동’이 아닌 학생만 조회하는 SQL문으로 옳은 것은?
    1.  `SELECT * FROM Student WHERE Name = '홍길동';`
    2.  `SELECT * FROM Student WHERE NOT Name = '홍길동';`
    3.  `SELECT * FROM Student WHERE Name LIKE ‘홍길동';`
    4.  `SELECT * FROM Student WHERE Age <> 20;`

    **정답: ②**
    **해설:** NOT 연산자를 사용하면 특정 조건을 반대로 적용한다. 여기서는 ‘홍길동'이 아닌 학생만 남는다.

6.  다음 SQL문이 수행하는 동작으로 옳은 것은?
    ```sql
    SELECT * FROM Student
    ORDER BY Age DESC
    LIMIT 2;
    ```
    1.  나이가 2세 이하인 학생만 출력한다.
    2.  나이를 기준으로 오름차순 정렬하여 상위 2명을 출력한다.
    3.  나이를 기준으로 내림차순 정렬하여 상위 2명을 출력한다.
    4.  이름 순으로 정렬하여 2명의 학생만 출력한다.

    **정답: ③**
    **해설:** `ORDER BY Age DESC`는 나이를 기준으로 큰 값부터 정렬한다. `LIMIT 2`는 그중 앞의 두 행만 가져온다.

7.  SELECT문에서 ORDER BY절을 사용하지 않을 경우, 기본적으로 데이터는 어떻게 출력되는가?
    1.  기본적으로 내림차순(DESC) 정렬되어 출력된다.

    **정답: ③**
    **해설:** SQL 표준에서는 ORDER BY가 없을 경우, 출력 순서를 보장하지 않는다. DBMS 내부 처리에 따라 결과 순서가 달라질 수 있다.

8.  다음 SQL문을 실행했을 때 출력되는 결과로 옳은 것은?
    ```sql
    SELECT * FROM Student
    ```

    **정답: ②**
    **해설:** IN은 괄호 안의 값 중 하나와 일치하면 결과를 반환한다. 따라서 '홍길동' 또는 '김철수'인 경우만 조회된다.

9.  다음 중 SQL에서 조회할 열 이름을 다른 이름으로 표시할 때 사용하는 기능은?

    2.  INDEX
    3.  PRIMARY KEY
    4.  DEFAULT

    **해설:** AS 키워드를 사용하여 별칭(Alias)을 부여할 수 있다. 예: `Age AS 나이`.

10. 다음 SQL문에서 LIMIT절의 역할로 알맞은 것은?
    ```sql
    SELECT * FROM Student

    ```
    1.  결과를 5열(column)까지만 출력한다.

## 제5장 SQL 기초 II: 데이터 조작

### 연습문제

1.  SQL에서 새로운 행(row)을 추가할 때 사용하는 명령어는?
    1.  UPDATE
    2.  INSERT
    3.  DELETE
    4.  SELECT

    **정답: ②**
    **해설:** INSERT는 테이블에 새로운 행을 삽입하는 명령어이다. UPDATE는 수정, DELETE는 삭제, SELECT는 조회에 해당한다.

2.  다음 SQL문이 수행하는 동작으로 옳은 것은?
    ```sql
    INSERT INTO Student VALUES (1, '홍길동', 23);
    ```
    1.  ID 1, 이름 ‘홍길동', 나이 23세인 학생을 추가한다.
    2.  ID 1, 이름 ‘홍길동' 학생의 나이를 23세로 수정한다.
    3.  ID 1인 학생을 삭제한다.
    4.  Student 테이블 전체 데이터를 조회한다.

    **정답: ①**
    **해설:** `INSERT INTO Student VALUES (...)` 구문은 새로운 학생 데이터를 추가한다. 수정이나 삭제와는 관련이 없다.

3.  다음 중 UPDATE문을 사용할 때 주의해야 할 점으로 알맞은 것은?
    1.  WHERE절을 생략하면 에러가 발생한다.
    2.  WHERE절을 생략하면 모든 행이 변경된다.
    3.  UPDATE문은 기본키(PK)만 수정할 수 있다.
    4.  UPDATE문은 수치형 데이터만 수정할 수 있다.

    **정답: ②**
    **해설:** UPDATE는 WHERE절 조건이 없을 경우, 전체 테이블 데이터가 변경된다. 따라서 항상 조건을 지정해야 한다.

4.  다음 SQL문을 실행하면 어떤 결과가 나타나는가?
    ```sql
    UPDATE Product
    SET Price = Price + 500
    WHERE Name = '라면';
    ```
    1.  ‘라면'의 가격이 500원으로 바뀐다.
    2.  ‘라면'의 가격이 500원 올라간다.
    3.  모든 상품의 가격이 500원 올라간다.
    4.  ‘라면' 상품이 삭제된다.

    **정답: ②**
    **해설:** `SET Price = Price + 500`은 기존 가격에 500을 더하는 연산이다. 특정 상품(라면)만 조건에 따라 수정된다.

5.  테이블에서 특정 조건의 데이터를 삭제할 때 사용하는 명령어는?
    1.  DROP
    2.  TRUNCATE
    3.  DELETE
    4.  REMOVE

    **정답: ③**
    **해설:** DELETE는 테이블 구조는 유지하면서 특정 조건의 데이터를 삭제한다. DROP은 테이블 자체를 제거하는 명령어이다.

6.  다음 SQL문이 수행하는 동작으로 옳은 것은?
    ```sql
    DELETE FROM Customer;
    ```
    1.  Customer 테이블 전체를 삭제한다.
    2.  Customer 테이블 구조와 데이터를 모두 삭제한다.
    3.  Customer 테이블의 모든 행(row)을 삭제한다.
    4.  Customer 테이블의 특정 고객만 삭제한다.

    **정답: ③**
    **해설:** `DELETE FROM Customer;` 구문은 조건이 없으므로 테이블의 모든 데이터를 삭제한다. 구조는 그대로 남는다.

7.  NULL값에 대한 설명으로 옳은 것은?
    1.  NULL은 숫자 0과 같다.
    2.  NULL은 빈 문자열(' ')과 같다.
    3.  NULL은 값이 없는 상태를 의미한다.
    4.  NULL값은 연산 시 항상 0으로 처리된다.

    **정답: ③**
    **해설:** NULL은 0이나 빈 문자열과 다르며, 단순히 값이 존재하지 않음을 뜻한다. 연산 시 특별한 주의가 필요하다.

8.  다음 SQL문을 실행하면 Price 열에는 어떤 값이 저장되는가?

## 제6장 SQL 고급: 조인과 집계

### 연습문제

1.  2개 이상의 테이블을 연결하여 데이터를 조회할 때 사용하는 SQL 구문은?
    1.  UNION
    2.  JOIN
    3.  GROUP BY
    4.  HAVING

    **정답: ②**
    **해설:** 여러 테이블을 연결할 때 사용하는 구문은 JOIN이다. UNION은 집합 합치기, GROUP BY와 HAVING은 집계용이다.

2.  INNER JOIN의 특징으로 옳은 것은?
    1.  왼쪽 테이블의 모든 행을 출력한다.
    2.  오른쪽 테이블의 모든 행을 출력한다.
    3.  두 테이블에서 조건이 일치하는 행만 출력한다.
    4.  두 테이블의 모든 행을 출력한다.

    **정답: ③**
    **해설:** INNER JOIN은 두 테이블에서 조건이 맞는 행만 결과로 반환한다. 조건이 맞지 않으면 결과에서 제외된다.

3.  LEFT JOIN을 사용했을 때 나타날 수 있는 결과는?
    1.  오른쪽 테이블에만 있는 데이터가 모두 출력된다.
    2.  일치하지 않는 경우 NULL이 표시된다.
    3.  교집합만 출력된다.
    4.  두 테이블 데이터가 모두 제외된다.

    **정답: ②**
    **해설:** LEFT JOIN은 왼쪽 테이블의 모든 행을 유지하고, 오른쪽에 일치하는 값이 없으면 NULL을 출력한다.

4.  다음 SQL문이 출력하는 결과는 무엇인가?
    ```sql
    SELECT c.Name, COUNT(*) AS 구매횟수
    FROM Purchase p
    JOIN Customer c ON p.CustomerID = c.CustomerID
    GROUP BY c.Name;
    ```
    1.  고객별 총구매금액
    2.  고객별 총구매수량
    3.  고객별 구매 내역 건수
    4.  고객별 평균 구매수량

    **정답: ③**
    **해설:** `COUNT(*)`는 행의 개수를 세며, GROUP BY 고객 이름으로 묶으므로 고객별 구매 횟수가 출력된다.

5.  GROUP BY절을 사용하는 목적은?
    1.  데이터를 정렬하기 위해
    2.  데이터를 그룹 단위로 묶기 위해
    3.  데이터를 삭제하기 위해
    4.  새로운 테이블을 만들기 위해

    **정답: ②**
    **해설:** GROUP BY는 데이터를 특정 열 기준으로 묶어 요약한다. 정렬은 ORDER BY의 기능이다.

6.  다음 SQL문에서 사용된 집계함수는?
    ```sql
    SELECT pr.Name, SUM(p.Quantity) AS 총수량
    FROM Purchase p
    JOIN Product pr ON p.ProductID = pr.ProductID
    GROUP BY pr.Name;
    ```
    1.  AVG
    2.  COUNT
    3.  SUM
    4.  MIN

    **정답: ③**
    **해설:** SUM 함수는 수량이나 금액을 합산한다. AVG, MIN, MAX는 각각 평균, 최솟값, 최댓값을 계산한다.

7.  다음 SQL문에서 출력되는 결과는?
    ```sql
    SELECT c.Name, SUM(pr.Price * p.Quantity) AS 총구매금액
    FROM Purchase p
    JOIN Customer c ON p.CustomerID = c.CustomerID
    JOIN Product pr ON p.ProductID = pr.ProductID
    GROUP BY c.Name
    HAVING SUM(pr.Price * p.Quantity) >= 5000;
    ```
    1.  총구매금액이 5000 이상인 고객만 출력된다.
    2.  모든 고객의 총구매금액이 출력된다.
    3.  총구매수량이 5000 이상인 고객이 출력된다.
    4.  고객별 평균 구매금액이 출력된다.

    **정답: ①**
    **해설:** `HAVING SUM(...) >= 5000` 조건은 그룹별 총합이 5000 이상인 경우만 남긴다.

8.  다음 중 집계함수가 아닌 것은?
    1.  COUNT
    2.  AVG
    3.  SUM
    4.  SELECT

    **정답: ④**
    **해설:** COUNT, SUM, AVG 등은 집계함수이지만 SELECT는 단순 열 조회 구문이다.

9.  HAVING절의 역할로 알맞은 것은?
    1.  개별 행(row)에 조건을 지정한다.
    2.  그룹화된 결과에 조건을 지정한다.
    3.  데이터를 정렬한다.
    4.  테이블의 구조를 변경한다.

    **정답: ②**
    **해설:** HAVING은 그룹화된 결과(집계값)에 조건을 주는 절이다. WHERE는 개별 행에 조건을 준다.

10. 카테고리별 총판매금액을 구하려면 적절한 SQL문의 형태는?
    1.  `SELECT Category, SUM(Price * Quantity) FROM Product;`
    2.  `SELECT Category, SUM(Price * Quantity) FROM Purchase GROUP BY Category;`
    3.  `SELECT pr.Category, SUM(pr.Price * p.Quantity) FROM Purchase p JOIN Product pr ON p.ProductID = pr.ProductID GROUP BY pr.Category;`
    4.  `SELECT pr.Category, pr.Price FROM Product pr;`

    **정답: ③**
    **해설:** 상품 카테고리별 총판매금액을 구하려면 Product와 Purchase를 조인하고, `Price * Quantity` 합계를 `GROUP BY Category`로 집계해야 한다.

## 제8장 파이썬과 데이터베이스의 연동

### 연습문제

1.  다음 중 파이썬과 데이터베이스를 연동하는 주요 이유로 보기 어려운 것은?
    1.  반복 작업 자동화
    2.  고급 분석·시각화 통합
    3.  이질적 데이터 소스 결합
    4.  엑셀 ODBC 드라이버 없이도 연결

    **정답: ④**
    **해설:** 파이썬과 DB 연동의 주요 이유는 자동화, 고급 분석 통합, 이질적 소스 결합이다. 엑셀 ODBC 드라이버 문제는 부수적인 편의성에 불과하다.

2.  파이썬의 sqlite3 라이브러리에 대한 설명으로 옳은 것은?
    1.  외부 패키지 설치가 필수이다.
    2.  서버 프로세스가 꼭 필요하다.
    3.  표준 라이브러리로 제공되어 즉시 사용할 수 있다.
    4.  네트워크 전용 DB여서 파일로 쓸 수 없다.

    **정답: ③**
    **해설:** sqlite3는 파이썬 표준 라이브러리로 별도 설치 없이 바로 사용 가능하며, 파일 기반 DB로 서버가 필요 없다.

3.  연결(connection)과 커서(cursor)의 역할 연결이 올바른 것은?
    1.  연결 - SQL 실행, 커서 - 트랜잭션 관리
    2.  연결 - DB와 통신·트랜잭션, 커서 - SQL 실행
    3.  연결 - 행 변환, 커서 - 시각화
    4.  연결 - 정렬, 커서 - 집계

    **정답: ②**
    **해설:** connection 객체는 DB와의 연결 및 트랜잭션 관리를 담당하고, cursor 객체는 SQL 명령을 실행하고 결과를 조회하는 역할을 한다.

4.  다음 중 데이터베이스 작업의 권장 흐름으로 가장 알맞은 것은?
    1.  커서 생성 → 연결 생성 → 실행 → 연결 종료
    2.  실행 → 커서 생성 → 가져오기 → 연결 종료
    3.  연결 생성 → 커서 생성 → SQL 실행 → 결과 가져오기 → 결과 사용 → 연결 종료
    4.  연결 생성 → 결과 가져오기 → SQL 실행 → 연결 종료

    **정답: ③**
    **해설:** 올바른 작업 흐름은 연결 생성 → 커서 생성 → SQL 실행 → 결과 가져오기 → 결과 사용 → 연결 종료 순이다.

5.  `with sqlite3.connect(...) as conn:` 패턴 사용 시 얻는 이점으로 옳은 것은?
    1.  자동 인덱스 생성
    2.  자동 커밋만 수행
    3.  블록 종료 시 예외 여부와 무관하게 연결이 정리된다.
    4.  커서가 필요 없다.

    **정답: ③**
    **해설:** with 구문은 블록 종료 시 오류 발생 여부와 관계없이 자동으로 연결을 정리하여 시스템 자원을 안전하게 해제한다.

6.  fetchone, fetchmany(n), fetchall에 대한 설명으로 옳지 않은 것은?
    1.  fetchone은 한 행만 반환한다.
    2.  fetchmany(n)은 최대 n개의 행을 리스트로 반환한다.
    3.  fetchall은 남은 모든 행을 한꺼번에 반환한다.
    4.  이들 메서드는 항상 열 이름으로 접근 가능한 딕셔너리를 반환한다.

    **정답: ④**
    **해설:** fetch 메서드는 기본적으로 튜플 형식을 반환한다. 열 이름으로 접근하려면 row_factory를 설정해야 한다.

7.  `conn.row_factory = sqlite3.Row`를 설정하면 얻는 효과는?
    1.  트랜잭션 자동 롤백
    2.  열 이름으로 값 접근 가능
    3.  데이터 자동 정렬
    4.  네트워크 연결 활성화

    **정답: ②**
    **해설:** `row_factory`를 `sqlite3.Row`로 설정하면 결과를 딕셔너리처럼 열 이름으로 접근할 수 있다.

8.  pandas.read_sql_query() 사용의 장점으로 보기 어려운 것은?
    1.  결과를 곧바로 DataFrame으로 받는다.
    2.  별도 커서 조작 없이도 동작한다.
    3.  head(), describe() 등으로 즉시 탐색 가능하다.
    4.  트랜잭션을 자동으로 커밋한다.

    **정답: ④**
    **해설:** `read_sql_query()`는 SELECT문 실행에 사용되며, 트랜잭션 커밋과는 무관하다. 커밋은 INSERT, UPDATE, DELETE 등에서 필요하다.

9.  사용자 입력을 포함하는 WHERE절을 안전하게 작성하려면 어떻게 해야 하는가?
    1.  문자열 포매팅으로 직접 합친다.
    2.  전역 변수에 저장한다.
    3.  `?` 자리표시자와 `params=`를 사용한다.
    4.  `SELECT *`로 모두 조회한다.

    **정답: ③**
    **해설:** SQL 인젝션을 방지하려면 `?` 자리표시자를 사용하여 파라미터를 안전하게 전달해야 한다. 문자열 포매팅으로 직접 결합하면 보안 취약점이 발생한다.

10. `DataFrame.to_sql(..., if_exists=?)`에서 `?` 자리에 append를 넣는 경우의 의미로 옳은 것은?
    1.  기존 테이블이 있으면 실패한다.
    2.  기존 테이블을 삭제 후 재생성한다.
    3.  기존 테이블에 새 행을 덧붙인다.
    4.  기존 인덱스만 교체한다.

    **정답: ③**
    **해설:** `if_exists='append'`는 기존 테이블을 유지하면서 새로운 행을 추가한다. ‘fail'은 오류 발생, ‘replace'는 테이블 교체를 의미한다.
