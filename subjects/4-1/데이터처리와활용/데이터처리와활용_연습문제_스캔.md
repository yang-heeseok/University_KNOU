### 연습문제

2. 행 - 속성, 열 - 튜플

4. 행 - 레코드, 열 - 엔티티

1. 개체 무결성 - 외래키는 중복 불가
2. 개체 무결성 - 기본키는 NULL 불가
3. 참조 무결성 - 기본키는 반드시 존재
4. 참조 무결성 - 기본키는 고유해야 함

**4. 학생(학번, 이름, 학과)과 학과(학과코드, 학과명) 테이블이 있을 때, 학생의 학과 속성이 학과의 학과코드 속성을 참조한다. 학과:학생의 관계 유형과 외래키 위치의 올바른 조합은?**

2. 1:N, 학과에 외래키
3. 1:N, 학생에 외래키
4. M:N, 연결 테이블 필요

4. 트리거로 양방향 삽입을 강제한다.

**6. 다음 설명과 가장 가까운 이상(anomaly)은?**

4. 인덱스만 추가한다.

**9. ER 다이어그램을 테이블로 변환하는 규칙으로 옳은 것은?**

**10. 다음 중 '도메인 무결성'의 예로 적절한 것은?**

## 제4장 SQL 기초 I: SELECT문 (p.79)

**2. 다음 중 SQL에서 두 조건이 모두 참일 때만 결과를 반환하도록 하는 연산자는?**

2. NOT
3. AND
4. LIKE

**3. 다음 SQL문이 의미하는 것은 무엇인가?**
```sql
1: SELECT * FROM Student
2: WHERE Age BETWEEN 20 AND 30;
```
1. 나이가 정확히 20세 또는 30세인 학생만 조회한다.
2. 나이가 20세 이상, 30세 이하인 학생을 조회한다.
3. 나이가 20세 미만 또는 30세 초과인 학생을 조회한다.
4. 나이가 25세인 학생만 조회한다.

**4. 문자열 검색을 위한 SQL 연산자로, %와 _ 와일드카드를 사용하는 것은?**
1. LIKE
2. IN
3. NOT
4. BETWEEN

**5. 다음 중 이름이 ‘홍길동'이 아닌 학생만 조회하는 SQL문으로 옳은 것은?**

2. `SELECT * FROM Student WHERE NOT Name = '홍길동';`
3. `SELECT * FROM Student WHERE Name LIKE '홍길동';`
4. `SELECT * FROM Student WHERE Age <> 20;`

**6. 다음 SQL문이 수행하는 동작으로 옳은 것은?**
```sql
1: SELECT * FROM Student
2: ORDER BY Age DESC
3: LIMIT 2;
```
1. 나이가 2세 이하인 학생만 출력한다.
2. 나이를 기준으로 오름차순 정렬하여 상위 2명을 출력한다.
3. 나이를 기준으로 내림차순 정렬하여 상위 2명을 출력한다.
4. 이름 순으로 정렬하여 2명의 학생만 출력한다.

**7. SELECT문에서 ORDER BY절을 사용하지 않을 경우, 기본적으로 데이터는 어떻게 출력되는가?**
1. 기본적으로 내림차순(DESC) 정렬되어 출력된다.
2. 기본적으로 오름차순(ASC) 정렬되어 출력된다.

4. 기본키(PK)를 기준으로 자동 정렬된다.

**8. 다음 SQL문을 실행했을 때 출력되는 결과로 옳은 것은?**

2. 이름이 ‘홍길동' 또는 ‘김철수'인 학생이 출력된다.
3. 이름이 ‘홍길동'인 학생은 제외하고, ‘김철수'만 출력된다.
4. 조건과 무관하게 모든 학생이 출력된다.

**9. 다음 중 SQL에서 조회할 열 이름을 다른 이름으로 표시할 때 사용하는 기능은?**
1. ALIAS

**10. 다음 SQL문에서 LIMIT절의 역할로 알맞은 것은?**

1. 결과를 5열(column)까지만 출력한다.
