<a id="c1-prob-4"></a>

> **정답: ② JSON API 응답**
> **해설**: 반정형은 태그·마크업으로 자기기술적 구조를 갖는 데이터로 JSON이 대표적이다.

<a id="c1-prob-5"></a>
**5. 📌 ⭐⭐ [이해] 정형 데이터의 특징**

> **해설**: 정형 데이터는 전체의 약 20%이고, 비정형이 약 80%를 차지한다.

<a id="c1-prob-6"></a>

> **정답: ③ 키-연속형**
> **해설**: 키는 연속형이다. 학생 수는 이산형, 온도는 연속형, 시간은 연속/구간형이다.

<a id="c1-prob-7"></a>
**7. 📌 ⭐ [기억] 데이터 품질 5요소**
> **정답: ② 복잡성**
> **해설**: 품질 요소는 정확성·완전성·일관성·적시성·유효성 등이며 '복잡성'은 포함되지 않는다.

<a id="c1-prob-8"></a>
**8. 📌 ⭐ [이해] 완전성**
> **정답: ② 완전성 부족**
> **해설**: 필수 항목 누락은 완전성(completeness) 문제이다.

> **해설**: 원시 데이터에 맥락을 부여해 의미 있는 정보로 만드는 과정이다.

<a id="c1-prob-10"></a>
**10. 📌 ⭐ [이해] 비정형 처리**
> **정답: ④ 동영상-SQL 쿼리 (적절하지 않음)**
> **해설**: SQL은 정형 데이터용이며, 동영상(비정형)은 컴퓨터 비전 등으로 처리한다.

## 제2장 관계형 데이터 모델 (p.45)

### ❓ 연습 문제 및 해설

> **블룸 인지 수준 범례**: [기억] 정의·나열 → [이해] 설명·비교 → [적용] 계산·구현 → [분석] 구별·디버그 → [평가] 판단·비평 → [창조] 설계·제안

#### 📝 문제

**1. 📌 ⭐ [이해] [파일 시스템 대비 데이터베이스의 장점으로 보기 어려운 것은?](#c2-prob-1)**

<a id="c2-prob-1"></a>
**1. 📌 ⭐ [이해] DB의 장점**
> **정답: ④ 파일 간 수동 동기화**
> **해설**: 수동 동기화는 파일 시스템의 단점이다. DB는 중복 최소화·권한 통제·백업/복구를 제공한다.

<a id="c2-prob-2"></a>
**2. 📌 ⭐ [기억] 관계형 용어**
> **정답: ③ 행-튜플, 열-속성**
> **해설**: 행=튜플(레코드), 열=속성(필드)이다.

<a id="c2-prob-3"></a>
**3. 📌 ⭐⭐ [기억/이해] 무결성 제약**
> **정답: ② 개체 무결성-기본키 NULL 불가**
> **해설**: 개체 무결성은 기본키가 NULL일 수 없음을, 참조 무결성은 외래키가 참조 테이블의 PK(또는 NULL)여야 함을 규정한다.

<a id="c2-prob-4"></a>
**4. 📌 ⭐⭐ [적용] 관계 유형과 FK**
> **정답: ③ 1:N, 학생에 FK**
> **해설**: 한 학과에 여러 학생(1:N)이며, FK(학과코드)는 N쪽인 학생 테이블에 둔다.

<a id="c2-prob-5"></a>
**5. 📌 ⭐⭐ [이해] M:N 구현**
> **정답: ③ 연결(조인) 테이블로 양쪽 참조**
> **해설**: M:N은 연결 테이블을 만들어 양쪽 PK를 FK로 참조한다.

<a id="c2-prob-6"></a>
**6. 📌 ⭐⭐ [이해] 삽입이상**
> **정답: ② 삽입이상**
> **해설**: 불필요한 값을 억지로 채워야 입력 가능한 문제가 삽입이상이다.

<a id="c2-prob-7"></a>
**7. 📌 ⭐⭐ [이해/분석] 부분 함수 종속**
> **정답: ② 2NF**
> **해설**: 복합키의 일부에만 의존(부분 함수 종속)하면 2NF를 위배한다.

<a id="c2-prob-8"></a>
**8. 📌 ⭐⭐ [이해] 3NF 분해**
> **정답: ① 결정자를 기본키로 하는 별도 테이블 분리**
> **해설**: 이행 종속의 중간 결정자를 PK로 하는 테이블로 분리하면 3NF가 된다.

<a id="c2-prob-9"></a>
**9. 📌 ⭐⭐ [이해] ER→테이블 변환**
> **정답: ③ M:N은 연결 테이블로 변환**
> **해설**: M:N 관계는 연결 테이블로 변환한다. (1:N은 N쪽에 FK 추가)

<a id="c2-prob-10"></a>
**10. 📌 ⭐⭐ [이해] 도메인 무결성**
> **정답: ③ 학년 값은 1~4 정수**
> **해설**: 도메인 무결성은 속성 값이 허용 범위·자료형을 따르도록 한다.

### ✅ O/X 확인문제

**1.** 관계형에서 행은 튜플, 열은 속성이다. (#c2-ox-1) **(O / X)**
**2.** 개체 무결성은 기본키가 NULL일 수 없음을 규정한다. (#c2-ox-2) **(O / X)**
**3.** 1:N 관계에서 외래키는 N쪽 테이블에 둔다. (#c2-ox-3) **(O / X)**
**4.** M:N 관계는 연결 테이블로 구현한다. (#c2-ox-4) **(O / X)**
**5.** 복합키의 일부에만 의존하는 속성은 3NF를 위배한다. (#c2-ox-5) **(O / X)**

<details>
<summary>O/X 정답 및 해설 보기 (클릭)</summary>

> <a id="c2-ox-1"></a>
> **1. 정답: O**
> **해설**: 행=튜플, 열=속성.

> <a id="c2-ox-2"></a>
> **2. 정답: O**
> **해설**: 개체 무결성의 정의이다.

> <a id="c2-ox-3"></a>
> **3. 정답: O**
> **해설**: FK는 N쪽에 둔다.

> <a id="c2-ox-4"></a>
> **4. 정답: O**
> **해설**: 연결 테이블로 구현한다.

> <a id="c2-ox-5"></a>
> **5. 정답: X**
> **해설**: 부분 함수 종속은 2NF 위배이다(3NF 아님).

</details>
