## 📝 요약 (Summary)
1. 🔴 **statsmodels OLS**: 파이썬의 회귀분석은 주로 `statsmodels`로 수행한다. 배열 기반 `sm.OLS(y, X)`와 R식 수식 기반 `smf.ols('y ~ x', data)` 두 방식이 있고, 둘 다 `.fit()`으로 적합한다.
2. 🔴 **절편 처리(add_constant)**: `sm.OLS`는 절편을 자동으로 넣지 않으므로 `sm.add_constant(X)`로 1열을 직접 추가해야 한다. 반면 `smf.ols`는 R의 `lm()`처럼 절편을 **자동 포함**한다 (`~ x` 안에 `1`이 묵시적).
3. 🔴 **.summary() 해석**: 적합 결과의 `.summary()`는 R `summary(lm())`과 같은 정보를 준다 — 계수 `coef`, 표준오차 `std err`, $t$값, $p$값($P>|t|$), $R^2$, 수정 $R^2$, $F$-통계량과 그 $p$값.
4. 🟡 **단순회귀(1장)**: 설명변수 1개. `smf.ols('y ~ x', df).fit()`로 적합하고 회귀직선·예측·잔차를 얻는다.
5. 🟡 **중회귀(2장)**: 설명변수 여러 개. `smf.ols('y ~ x1 + x2', df).fit()`로 적합하고, `sm.stats.anova_lm(model)`으로 분산분석표를 출력한다.
6. 🟢 **R과의 비교**: `lm`↔`ols`, `summary`↔`.summary()`, `coef`↔`.params`, `predict`↔`.predict()`, `resid`↔`.resid`, `anova`↔`anova_lm`로 거의 1:1 대응된다.

## 📐 핵심 문법 및 패턴 (Key Syntax & Patterns)

> 본 강의는 **실습 중심**이므로 수식 대신 "패턴 → 코드 → 용도"로 정리한다.

| 패턴명 | 코드 | 용도 |
| :--- | :--- | :--- |
| **모듈 임포트** | `import statsmodels.api as sm`<br>`import statsmodels.formula.api as smf` | 배열 API(`sm`) / 수식 API(`smf`) |
| **절편 추가** | `X = sm.add_constant(x)` | $X$의 1열($\beta_0$용) 추가 |
| **배열식 적합** | `model = sm.OLS(y, X).fit()` | $\mathbf y, X$ 직접 지정 |
| **수식식 적합** | `model = smf.ols('y ~ x', data=df).fit()` | R `lm(y~x)`와 동일, 절편 자동 |
| **결과 요약** | `print(model.summary())` | R `summary(fit)` |
| **계수** | `model.params` | $\hat\beta_0,\hat\beta_1,\dots$ (R `coef`) |
| **표준오차/t/p** | `model.bse`, `model.tvalues`, `model.pvalues` | 개별 계수 추론 |
| **신뢰구간** | `model.conf_int()` | R `confint(fit)` |
| **결정계수** | `model.rsquared`, `model.rsquared_adj` | $R^2$, 수정 $R^2$ |
| **F-통계량** | `model.fvalue`, `model.f_pvalue` | 회귀 전체 유의성 |
| **적합값/잔차** | `model.fittedvalues`, `model.resid` | $\hat y_i$, $e_i$ (R `fitted`,`resid`) |
| **예측** | `model.predict(new_df)` | 새 데이터 예측 (R `predict`) |
| **중회귀** | `smf.ols('y ~ x1 + x2', df).fit()` | 설명변수 여러 개 |
| **분산분석표** | `sm.stats.anova_lm(model)` | SSR·SSE·F (R `anova`) |
| **상호작용/변환** | `'y ~ x1*x2'`, `'y ~ np.log(x)'` | 교호작용·변수변환 |

### 핵심 정의 및 원리

**절편 처리 — Python 회귀의 1순위 함정**
$$
\texttt{sm.OLS}:\ \text{절편 수동}\quad\Big(\,X=[\mathbf 1\ \ \mathbf x]\,\Big)
\qquad\text{vs}\qquad
\texttt{smf.ols('y \~ x')}:\ \text{절편 자동}
$$
> **직관적 해석**: `sm.OLS(y, x)`에 `add_constant`를 빠뜨리면 **원점을 지나는 회귀**($y=\beta_1 x$)가 적합되어 R `lm(y~x)`와 결과가 달라진다. 절편을 강제로 빼려면 R은 `lm(y~x-1)`, Python 수식은 `'y ~ x - 1'` 또는 `'y ~ x + 0'`을 쓴다.
> **AI 적용**: scikit-learn `LinearRegression(fit_intercept=True)`이 `add_constant`의 자동화 버전. 특징행렬 설계 시 절편(bias) 포함 여부는 모든 선형모델의 기본 점검 항목이다.

## ✏️ 심화 학습 (Study Subject)

### 1. 가상 시나리오: "어떤 개념을, 언제 사용해야 할까?"
- **상황**: R로 분석하던 회귀모형을 팀의 Python 파이프라인으로 이식해야 한다. 동료가 `sm.OLS(y, x).fit()`로 짠 코드의 기울기·$R^2$가 R `lm(y~x)`와 미묘하게 다르다.
- **문제**: 같은 데이터인데 왜 결과가 다를까? Python에서 R과 **동일한** 회귀를 재현하려면 무엇을 고쳐야 할까?
- **해결**: 원인은 절편 누락이다. `sm.OLS`는 절편을 자동 추가하지 않으므로
  ```python
  X = sm.add_constant(x)          # 1열 추가 → 절편 β0 포함
  model = sm.OLS(y, X).fit()
  ```
  로 고치거나, 처음부터 R과 같은 수식 API
  ```python
  model = smf.ols('y ~ x', data=df).fit()   # lm(y~x)와 동일
  ```
  를 쓴다. 그러면 `model.params`의 절편·기울기, `model.rsquared`가 R과 일치한다.
- **AI 학습 포인트**: "scikit-learn `LinearRegression`, statsmodels `sm.OLS`, `smf.ols`, R `lm`의 절편 처리 기본값을 표로 비교하고, 절편 없는 회귀가 적절한 상황(예: 물리적으로 원점을 지나야 하는 모형)을 예로 들어줘."

### 2. 관점별 비교 및 오개념 분석
- **핵심 비교**:
  - **`sm.OLS` vs `smf.ols`**: 전자는 배열($\mathbf y, X$)을 직접 받고 절편 수동, 후자는 `DataFrame` + R식 문자열 수식이고 절편 자동.
  - **`.summary()` vs `anova_lm`**: 전자는 **계수 중심**(추정·$t$·$p$·$R^2$), 후자는 **변동분해 중심**(SSR·SSE·$F$). 회귀 전체 $F$는 양쪽 모두에서 확인 가능.
  - **statsmodels vs scikit-learn**: 전자는 통계적 추론(표준오차·$p$값·신뢰구간)이 풍부, 후자는 예측·ML 파이프라인 중심(추론 정보 빈약).
- **오개념 분석**:
    - **오개념 1**: "`sm.OLS(y, x)`는 R `lm(y~x)`와 똑같다."
    - **분석**: 틀렸다. `add_constant`를 안 하면 절편이 빠져 원점 통과 회귀가 된다. R과 동일하려면 `sm.add_constant(x)` 또는 `smf.ols('y ~ x')`.
    - **오개념 2**: "`.summary()`의 $R^2$가 높으면 각 변수 모두 유의하다."
    - **분석**: $R^2$(전체 설명력)와 개별 계수의 $p$값(`P>|t|`)은 별개다. $R^2$가 높아도 특정 계수의 $p$값이 크면 그 변수는 유의하지 않다(다중공선성 등).
    - **오개념 3**: "`anova_lm`의 변수별 제곱합은 변수 입력 순서와 무관하다."
    - **분석**: 기본 `anova_lm`(Type I, 순차적 SS)은 **입력 순서에 의존**한다. 순서 무관한 분해를 원하면 `typ=2`(Type II)를 지정한다: `anova_lm(model, typ=2)`.
- **AI 학습 포인트**: "statsmodels `.summary()` 출력의 각 칸(coef, std err, t, P>|t|, [0.025 0.975], R-squared, F-statistic, Prob(F))이 R `summary(lm())`의 어느 항목과 대응하는지 한 줄씩 매핑해줘."

<a id="prob-1"></a>
**1. ⭐ [기억] 회귀분석 라이브러리**
> **정답: ② `statsmodels`**
> **해설**: `statsmodels`는 R의 `lm`/`summary`처럼 계수·표준오차·$t$·$p$·$R^2$·$F$ 등 **통계적 추론**을 제공한다. `matplotlib`/`seaborn`은 시각화, `requests`는 HTTP 통신용. (scikit-learn도 회귀를 하지만 추론 정보는 빈약하다.)

<a id="prob-2"></a>
**2. ⭐ [기억] 절편 추가**
> **정답: ② `sm.add_constant(x)`로 1열을 추가한다**
> **해설**: `sm.OLS`는 절편을 자동 포함하지 않는다. `sm.add_constant(x)`로 모두 1인 열을 붙여야 $\hat\beta_0$(절편)가 추정된다. 빠뜨리면 원점 통과 회귀가 되어 R 결과와 달라진다. 표준화·로그변환·정렬은 절편과 무관.

<a id="prob-3"></a>
**3. ⭐ [이해] 수식 API**
> **정답: ③ `smf.ols('y ~ x1 + x2', data=d).fit()`**
> **해설**: 수식 API는 `smf.ols`이고 R식 `~` 기호와 `+`로 변수를 나열하며 `data=`로 데이터프레임을 넘긴다. ①은 `=`(틀림), ②는 배열 API `sm.OLS`에 문자열을 넣어 오류, ④ `smf.lm`은 존재하지 않는 함수.

<a id="prob-4"></a>
**4. ⭐⭐ [이해] 결과 객체 속성**
> **정답: ② 가, 나, 다**
> **해설**: 계수 `model.params`, 결정계수 `model.rsquared`, 잔차 `model.resid` 모두 옳다. **라**는 틀림 — 예측은 `model.predict(new_df)`이고, `model.summary()`는 종합 요약표를 출력한다.

<a id="prob-5"></a>
**5. ⭐⭐ [이해] summary 해석**
> **정답: ③ `P>|t|`**
> **해설**: `P>|t|`는 귀무가설 $H_0:\beta_j=0$에 대한 개별 계수의 $p$값으로, 보통 $<0.05$면 유의하다고 본다. `coef`는 추정값, `std err`는 표준오차, `R-squared`는 모형 전체 설명력(개별 계수 유의성과 별개).

<a id="prob-6"></a>
**6. ⭐⭐ [적용] 회귀식·예측**
> **정답: ② $\hat y = 2 + 0.5x$, 예측 7.0**
> **해설**: `const`(절편)$=2$, `x`(기울기)$=0.5$이므로 $\hat y=2+0.5x$. $x=10$이면 $\hat y=2+0.5\times10=7.0$. statsmodels는 출력에서 절편을 `const`로 표기한다.

<a id="prob-7"></a>
**7. ⭐⭐ [분석] 분산분석표 코드**
> **정답: ② ㉠ `smf.ols`, ㉡ `anova_lm`**
> **해설**: 수식 적합은 `smf.ols(...).fit()`, 분산분석표는 `sm.stats.anova_lm(model)`. `summary`/`predict`는 분산분석표(SSR·SSE·$F$ 분해)를 만들지 않는다. (순서 무관 분해는 `anova_lm(model, typ=2)`.)

<a id="prob-8"></a>
**8. ⭐⭐⭐ [분석] R²가 비정상적으로 높은 원인**
> **정답: ② `add_constant`를 빠뜨려 절편 없는(원점 통과) 회귀가 적합되었다**
> **해설**: 절편 없는 모형에서 statsmodels는 $R^2$를 **평균이 아닌 0 기준(uncentered)** 으로 계산하여 흔히 1에 가깝게 부풀려진다. 따라서 절편 포함 모형의 $R^2$와 직접 비교하면 안 된다. R과 동일하게 하려면 `sm.add_constant(x)` 또는 `smf.ols('y~x')`를 사용한다.

<a id="prob-9"></a>
**9. ⭐⭐⭐ [평가] 도구 선택**
> **정답: ② statsmodels — 통계적 추론을 기본 제공하므로**
> **해설**: 표준오차·$p$값·신뢰구간·$F$검정 등 추론 결과가 필요한 보고서에는 `.summary()`를 주는 statsmodels가 적합하다. scikit-learn은 `.summary()`가 없고 예측·파이프라인에 강점이 있다(④의 진술은 거짓).

<a id="prob-10"></a>
**10. ⭐⭐⭐ [창조] 중회귀 적합·요약·예측 (서술형)**
> **정답·해설 (예시 코드)**:
> ```python
> import pandas as pd
> import statsmodels.api as sm
> import statsmodels.formula.api as smf
>
> # ① 중회귀 적합 (절편 자동 포함)
> model = smf.ols('y ~ x1 + x2', data=df).fit()
>
> # ② 요약 + 분산분석표
> print(model.summary())
> print(sm.stats.anova_lm(model, typ=2))
>
> # ③ 새 관측치 예측 (x1=5, x2=3)
> new = pd.DataFrame({'x1': [5], 'x2': [3]})
> print(model.predict(new))
> ```
> **R 대응 코드**:
> ```r
> fit <- lm(y ~ x1 + x2, data = df)   # ① 적합
> summary(fit); anova(fit)            # ② 요약·분산분석
> predict(fit, newdata = data.frame(x1 = 5, x2 = 3))  # ③ 예측
> ```
> **핵심**: `smf.ols`↔`lm`, `.summary()`↔`summary`, `anova_lm`↔`anova`, `.predict(new_df)`↔`predict(fit, newdata)`로 1:1 대응된다. 예측 시 새 데이터는 **학습 때와 같은 열 이름**을 가진 `DataFrame`이어야 한다.

## 💻 코드로 확인하기 (Code Verification)

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf

# 가상 데이터: 단순회귀 y = 3 + 2*x + 잡음
np.random.seed(0)
n = 40
x = np.random.uniform(0, 10, n)
y = 3 + 2*x + np.random.normal(0, 1.5, n)
df = pd.DataFrame({'x': x, 'y': y})

# ── 1장: 단순회귀 ───────────────────────────────
# (A) 배열 API — add_constant 필수
X = sm.add_constant(df['x'])           # 절편용 1열 추가
m_arr = sm.OLS(df['y'], X).fit()
print("배열 API params:\n", np.round(m_arr.params, 4))

# (B) 수식 API — R lm(y~x)와 동일 (절편 자동)
m_form = smf.ols('y ~ x', data=df).fit()
print("\n수식 API params:\n", np.round(m_form.params, 4))
print("R^2 =", round(m_form.rsquared, 4),
      " F =", round(m_form.fvalue, 2),
      " Prob(F) =", f"{m_form.f_pvalue:.2e}")

# 예측: x=5
print("predict(x=5) =", m_form.predict(pd.DataFrame({'x': [5]})).values)

# ── 2장: 중회귀 ─────────────────────────────────
df['x2'] = np.random.uniform(0, 5, n)
df['y2'] = 1 + 1.5*df['x'] - 0.7*df['x2'] + np.random.normal(0, 1.0, n)
m_mul = smf.ols('y2 ~ x + x2', data=df).fit()
print("\n중회귀 params:\n", np.round(m_mul.params, 4))
print("\n분산분석표(Type II):\n", sm.stats.anova_lm(m_mul, typ=2))

# 절편 누락 시 R^2가 부풀려짐을 확인 (오개념 검증)
m_noint = sm.OLS(df['y'], df['x']).fit()      # add_constant 안 함!
print("\n절편 없음 R^2 =", round(m_noint.rsquared, 4),
      " vs 절편 있음 R^2 =", round(m_form.rsquared, 4))
```

> **실행 결과 (실제 출력, `seed=0`)**
> ```
> 배열 API params:
>  const    2.2436
>  x        2.0391
> 수식 API params:
>  Intercept    2.2436
>  x            2.0391
> R^2 = 0.9481  F = 694.25  Prob(F) = 5.10e-26
> predict(x=5) = [12.4390789]         # ≈ 3 + 2*5 = 13 (잡음으로 다소 벗어남)
> 중회귀 params:
>  Intercept    1.8619
>  x            1.4664
>  x2          -0.8500
> 분산분석표(Type II):
>             sum_sq    df       F        PR(>F)
>  x         638.22   1.0  713.19  8.84e-26
>  x2         53.17   1.0   59.42  3.30e-09
>  Residual   33.11  37.0     NaN       NaN
> 절편 없음 R^2 = 0.9885  vs 절편 있음 R^2 = 0.9481
> ```
> **해석**: 배열 API(`const`)와 수식 API(`Intercept`)의 절편·기울기가 정확히 일치한다($2.2436,\ 2.0391$). 단순회귀의 기울기는 참값 $2$에 잘 맞지만, 절편은 참값 $3$보다 다소 작은 $2.24$로 나온다($n=40$의 표본 잡음 탓 — 절편·기울기 추정의 음의 상관 때문에 기울기가 약간 높으면 절편이 낮아진다). 중회귀도 기울기 $x$의 참값 $1.5$에는 가깝지만($1.4664$), 절편($b_0=1.8619$ vs 참값 $1$)과 $x_2$ 계수($-0.8500$ vs 참값 $-0.7$)는 다소 벗어나 있다 — 즉 추정계수가 참값에 "정확히 근접"한다기보다는 **표본 변동 범위 안에서 참값 주변에 분포**한다고 보는 것이 옳다. 예측값 $\approx12.44$도 모형식 $3+2\times5=13$과 같은 방향이되 잡음으로 약간 작다. 마지막 줄에서 **절편을 빠뜨린 모형의 $R^2$($0.9885$)가 절편 있는 모형($0.9481$)보다 더 커 보이는** 착시(uncentered $R^2$)를 직접 확인할 수 있다 — 절편 처리의 중요성을 보여준다.

## 🔬 심층 확장: `anova_lm` Type I vs Type II와 강건 표준오차

> 앞의 오개념 3에서 "기본 `anova_lm`(Type I)은 입력 순서에 의존한다"고 짚었다. 여기서는 **같은 모형·같은 데이터**에 `typ=1`과 `typ=2`를 나란히 돌려 그 순서 의존성을 실측으로 시연하고, 한 줄로 끝나는 **이분산 강건 SE**(`cov_type='HC3'`)를 덧붙인다.

### 1. Type I(순차적 SS) vs Type II(주변적 SS) — 순서 의존성 시연

`sm.stats.anova_lm(model, typ=...)`의 `typ` 인자는 제곱합(SS) 분해 방식을 정한다.

| 종류 | 정의 | 순서 의존성 | 한 변수의 SS 의미 |
| :--- | :--- | :--- | :--- |
| **Type I** (`typ=1`, 기본) | 변수를 **수식에 적은 순서대로** 하나씩 넣으며 SSR 증가분을 배분 | **있음** — 먼저 적은 변수가 공통 변동을 모두 가져감 | "이전 변수들이 들어간 뒤" 추가 기여분 |
| **Type II** (`typ=2`) | 각 변수를 **나머지 모든 (동급) 항이 이미 들어간 모형**에 마지막으로 넣었을 때의 추가 기여분 | **없음** — 순서를 바꿔도 동일 | 다른 변수를 통제한 고유 기여분 |
| **Type III** (`typ=3`) | 상호작용까지 포함해 각 항을 "전부 통제된" 상태에서 평가(코딩에 민감) | 없음 | 모든 항 통제 후 기여분 |

> **핵심**: Type I은 `y ~ x1 + x2`와 `y ~ x2 + x1`에서 **각 변수의 SS·F·p가 달라진다**. Type II/III는 동일하다. statsmodels 기본값은 **Type II**가 아니라 **Type I**(`typ=1`)이므로 R `anova()`(역시 Type I/순차적)와는 맞지만, R `car::Anova(..., type=2)`나 SAS 기본(Type III)과 대조할 때 혼동하기 쉽다.

상관된 두 설명변수($x_2\approx0.8x_1+$잡음)로 적합한 실측 결과는 다음과 같다.

```python
import numpy as np, pandas as pd
import statsmodels.api as sm, statsmodels.formula.api as smf

np.random.seed(0)
n = 50
x1 = np.random.normal(0, 1, n)
x2 = 0.8*x1 + np.random.normal(0, 0.6, n)        # x1, x2 상관
y  = 1 + 2*x1 + 1.0*x2 + np.random.normal(0, 1.0, n)
df = pd.DataFrame({'y': y, 'x1': x1, 'x2': x2})

m     = smf.ols('y ~ x1 + x2', data=df).fit()
m_rev = smf.ols('y ~ x2 + x1', data=df).fit()    # 변수 입력 순서만 바꿈

print(sm.stats.anova_lm(m,     typ=1))           # Type I:  x1 + x2
print(sm.stats.anova_lm(m_rev, typ=1))           # Type I:  x2 + x1
print(sm.stats.anova_lm(m,     typ=2))           # Type II: x1 + x2
print(sm.stats.anova_lm(m_rev, typ=2))           # Type II: x2 + x1
```

> **실행 결과 (실제 출력, `seed=0`)**
> ```
> === Type I (typ=1): y ~ x1 + x2 ===
>             df    sum_sq   mean_sq         F  PR(>F)
> x1         1.0  507.6248  507.6248  460.6478   0.000
> x2         1.0    6.5044    6.5044    5.9024   0.019
> Residual  47.0   51.7931    1.1020       NaN     NaN
>
> === Type I (typ=1): y ~ x2 + x1  (순서 바꿈) ===
>             df    sum_sq   mean_sq         F  PR(>F)
> x2         1.0  426.4790  426.4790  387.0115     0.0
> x1         1.0   87.6501   87.6501   79.5387     0.0
> Residual  47.0   51.7931    1.1020       NaN     NaN
>
> === Type II (typ=2): y ~ x1 + x2 ===
>            sum_sq    df        F  PR(>F)
> x1        87.6501   1.0  79.5387   0.000
> x2         6.5044   1.0   5.9024   0.019
> Residual  51.7931  47.0      NaN     NaN
>
> === Type II (typ=2): y ~ x2 + x1 (순서 바꿈) ===
>            sum_sq    df        F  PR(>F)
> x2         6.5044   1.0   5.9024   0.019
> x1        87.6501   1.0  79.5387   0.000
> Residual  51.7931  47.0      NaN     NaN
> ```
> **해석**: **Type I**에서는 먼저 적은 변수가 $x_1,x_2$의 **공통 변동**을 독차지한다 — `x1` 먼저면 `x1`의 SS가 $507.62$이지만, `x2` 먼저면 `x1`의 SS가 $87.65$로 격감한다(`x2`도 $426.48 \leftrightarrow 6.50$). 즉 **같은 데이터·같은 모형인데 변수 나열 순서만으로 각 변수의 SS·F·p가 통째로 바뀐다**. 반면 **Type II**는 항상 "다른 변수를 통제한 고유 기여분"($x_1{=}87.65$, $x_2{=}6.50$)을 주므로 **순서를 바꿔도 표의 행 순서만 바뀔 뿐 값은 불변**이다. 흥미롭게도 Type II의 두 값은 각각 Type I에서 그 변수를 **마지막에** 넣었을 때의 SS와 정확히 일치한다($x_1{=}87.65$는 `x2+x1`에서 `x1`의 Type I SS, $x_2{=}6.50$은 `x1+x2`에서 `x2`의 Type I SS). 한편 **Residual SSE($51.79$)는 네 경우 모두 동일** — 분해 방식이 바뀔 뿐 모형의 총 적합도는 같기 때문이다. 다중공선성이 있을 때 "어느 변수가 중요한가"를 순서 무관하게 보려면 `typ=2`를 써야 한다.

### 2. 이분산 강건 표준오차 한 줄: `.fit(cov_type='HC3')`

OLS의 표준 SE는 **등분산($\text{Var}(\epsilon_i)=\sigma^2$ 일정)** 가정에 기댄다. 이 가정이 깨지면(이분산) 계수 추정값 $\hat{\boldsymbol\beta}$ 자체는 여전히 불편이지만 **표준오차·$t$·$p$·CI가 틀어진다**. 이를 한 줄로 보정하는 것이 White(1980)의 **이분산 강건(heteroscedasticity-consistent) SE**이며, statsmodels는 `.fit()`에 `cov_type`만 넘기면 된다.

```python
m_hc3 = smf.ols('y ~ x1 + x2', data=df).fit(cov_type='HC3')   # 단 한 줄
print(m.bse)        # 기본(비강건) SE
print(m_hc3.bse)    # HC3 강건 SE  — 계수(params)는 그대로, SE만 달라짐
```

> **실행 결과 (실제 출력, `seed=0`)**
> ```
> === 기본(비강건) SE ===     === HC3 강건 SE ===
> Intercept    0.1496         Intercept    0.1537
> x1           0.2573         x1           0.2371
> x2           0.2859         x2           0.2601
> 계수(둘 다 동일): [1.2457  2.2943  0.6945]
> ```
> **해석**: `cov_type='HC3'`을 붙여도 **`params`(계수)는 한 글자도 안 바뀐다** — 바뀌는 것은 `bse`(표준오차)와 그에 따른 `tvalues`·`pvalues`·`conf_int()`뿐이다. 강건 SE는 잔차 $e_i$를 지렛대로 보정($\text{HC3}\approx e_i/(1-h_{ii})$)해 이분산 상황에서도 타당한 추론을 준다. **HC0~HC3** 중 **HC3**이 소표본에서 가장 보수적·안정적이라 권장된다(MacKinnon & White 1985). 위 예는 이분산을 일부러 넣지 않아 차이가 작지만($0.2573\to0.2371$ 등), 잔차 분산이 $x$에 따라 변하는 실제 데이터에서는 차이가 크게 벌어진다.

| 옵션 | 의미 | 권장 상황 |
| :--- | :--- | :--- |
| `cov_type='nonrobust'` (기본) | 등분산 가정 OLS SE | 등분산이 성립할 때 |
| `cov_type='HC0'` | White의 원형 강건 SE | 대표본 |
| `cov_type='HC3'` | 지렛대 보정 강건 SE | **소표본·이분산 의심 시 기본 권장** |
| `cov_type='HAC'` | 자기상관+이분산 강건 | 시계열 잔차 자기상관 |

> **R 대응**: R에서는 `lmtest::coeftest(fit, vcov = sandwich::vcovHC(fit, type="HC3"))`로 같은 결과를 얻는다. Python은 적합 시점에 `cov_type`만 지정하면 `.summary()` 전체가 강건 SE 기준으로 바뀐다는 점이 편리하다.
> **출처**: statsmodels [`get_robustcov_results`](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.OLSResults.get_robustcov_results.html), [`anova_lm`](https://www.statsmodels.org/stable/generated/statsmodels.stats.anova.anova_lm.html); MacKinnon & White (1985) HC1/HC2/HC3 소표본 권장.

## 📖 심화 학습 예시 답안

#### 1. `.summary()` 출력의 내부 구성 원리
statsmodels `.summary()`는 R `summary(lm())`과 동일한 세 블록으로 구성된다.

1. **모형 정보 블록**: `R-squared`, `Adj. R-squared`, `F-statistic`, `Prob (F-statistic)`, `No. Observations`, `Df Residuals/Model` — 모형 전체의 적합도와 유의성, 자유도.
2. **계수 블록**: 행마다 변수, `coef`($\hat\beta_j$), `std err`(표준오차 $=\sqrt{\sigma^2(X^\top X)^{-1}_{jj}}$ `→← 3강`), `t`($=\hat\beta_j/\text{se}$), `P>|t|`($p$값), `[0.025 0.975]`(95% CI).
3. **진단 블록**: `Omnibus`, `Durbin-Watson`(자기상관), `Jarque-Bera`(정규성), `Cond. No.`(다중공선성) — 가정 점검용.

#### 2. `sm.OLS` vs `smf.ols` 비교표

| 구분 | `sm.OLS(y, X)` (배열 API) | `smf.ols('y ~ x', df)` (수식 API) | 비고 |
| :--- | :--- | :--- | :--- |
| **입력** | NumPy 배열/Series ($\mathbf y, X$) | 문자열 수식 + `DataFrame` | |
| **절편** | 수동 (`add_constant`) | 자동 포함 | R `lm`과 같은 건 수식 API |
| **절편 표기** | `const` | `Intercept` | |
| **변수 변환** | 코드로 직접 | 수식 안에서 `np.log(x)`, `x1*x2` | 수식 API가 편리 |
| **AI 활용** | 행렬 직접 제어가 필요한 실험 | 빠른 R 스타일 분석·해석 | |

#### 3. R 코드를 Python으로 이식하는 법 (Best Practice)

- **Bad Practice (나쁜 예시)**
  ```python
  # R lm(y~x)를 옮긴다며 절편을 빠뜨림 → 원점 통과 회귀, R²·계수 불일치
  model = sm.OLS(y, x).fit()
  ```
- **Good Practice (좋은 예시)**
  ```python
  # 방법 1: R 스타일 수식 API (가장 직관적, 절편 자동)
  model = smf.ols('y ~ x', data=df).fit()

  # 방법 2: 배열 API라면 반드시 add_constant
  model = sm.OLS(df['y'], sm.add_constant(df['x'])).fit()
  ```
- **설명**: R `lm`은 절편을 자동 포함하므로, 이식할 때 절편 처리를 맞추는 것이 가장 흔한 실수의 원인이다. 수식 API를 쓰면 변수 변환(`np.log`, `*` 교호작용)까지 R 문법과 거의 동일하게 옮길 수 있다.

## 📚 핵심 용어집 (Glossary)

| 용어 (한) | 용어 (영) | 코드 표현 | 정의 |
| :--- | :--- | :--- | :--- |
| **statsmodels** | statsmodels | `import statsmodels.api as sm` | 통계 추론 중심 회귀 라이브러리 |
| **배열 API** | array interface | `sm.OLS(y, X)` | $\mathbf y, X$ 직접 입력, 절편 수동 |
| **수식 API** | formula interface | `smf.ols('y ~ x', df)` | R식 문자열 수식, 절편 자동 |
| **절편 추가** | add constant | `sm.add_constant(x)` | $X$에 1열 추가 (절편 $\beta_0$) `→← 2강` |
| **적합** | fit | `.fit()` | 최소제곱 추정 수행 |
| **요약표** | summary | `.summary()` | 계수·$R^2$·$F$ 종합 (R `summary`) |
| **추정계수** | coefficients | `.params` | $\hat\beta$ (R `coef`) |
| **결정계수** | R-squared | `.rsquared` | 설명된 변동 비율 `→← 3강` |
| **F-통계량** | F-statistic | `.fvalue` | 회귀 전체 유의성 `→← 3강` |
| **잔차** | residual | `.resid` | $e_i=y_i-\hat y_i$ `→← 3강` |
| **적합값** | fitted value | `.fittedvalues` | $\hat y_i$ |
| **예측** | predict | `.predict(new_df)` | 새 데이터 예측 (R `predict`) |
| **분산분석표** | ANOVA table | `sm.stats.anova_lm(model)` | SSR·SSE·$F$ (R `anova`) |
| **신뢰구간** | confidence interval | `.conf_int()` | 계수 95% CI (R `confint`) |
