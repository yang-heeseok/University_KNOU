10번 답:

**공통점**

경사 하강법과 역전파는 모두 신경망의 손실(loss)을 줄이는 최적의 파라미터(가중치 w, 바이어스 b)를 찾는 학습 과정에 쓰인다. 두 방법 모두 손실을 각 파라미터로 미분한 기울기(gradient) ∂loss/∂w를 핵심 정보로 사용한다. 기울기는 해당 파라미터가 손실에 미친 영향, 즉 '틀린 정도'를 나타낸다. 또한 두 과정은 한 번에 끝나지 않고 학습 데이터를 반복해서 보며(epoch) 함께 되풀이된다.

**차이점**

| 구분 | 경사 하강법(Gradient Descent) | 역전파(Back Propagation) |
| --- | --- | --- |
| 역할 | 기울기를 이용해 가중치를 **갱신**하는 최적화 기법 | 각 가중치에 대한 기울기를 **계산**하는 기법 |
| 핵심 식 | w_new = w_old − η·(∂loss/∂w) | 연쇄법칙: ∂loss/∂w = (∂loss/∂ŷ)·(∂ŷ/∂u)·(∂u/∂w) … |
| 진행 방향 | 손실이 낮아지는 방향(기울기의 반대 방향)으로 이동 | 출력층에서 입력층 쪽으로 거꾸로 전달 |
| 주요 설정값 | 보폭 크기(learning rate, η) | 별도 설정값 없음(미분 규칙에 따라 계산) |
| 적용 범위 | 선형 회귀처럼 단순한 모델에도 바로 적용 가능 | 합성 함수와 활성 함수가 여러 겹 중첩된 다층 신경망에서 특히 필요 |

경사 하강법은 현재 가중치에서 기울기에 보폭 크기를 곱한 만큼 빼는 방식으로 손실의 극소 지점을 찾아간다. 기울기가 0에 가까워질 때까지 이 갱신을 반복한다. 보폭 크기가 너무 크면 극소점을 지나쳐 손실이 발산할 수 있고, 너무 작으면 학습이 느려진다.

그런데 은닉층이 있는 모델의 예측값은 ŷ = φ(w₂·φ(w₁x + b₁) + b₂)처럼 함수가 깊게 중첩되어 있다. 따라서 수많은 가중치 각각의 기울기를 하나씩 직접 구하기 어렵다. 역전파는 미분의 연쇄법칙을 이용해 이 문제를 해결한다. 출력층의 오차에서 시작하여 마지막 층부터 앞쪽 층으로 기울기를 차례로 전달하고, 앞 단계에서 구한 값을 재사용하여 모든 가중치의 기울기를 효율적으로 계산한다.

정리하면 역전파는 "각 가중치를 어느 방향으로 얼마나 고쳐야 하는가"를 알려 주는 계산 단계이고, 경사 하강법은 그 정보를 받아 실제로 가중치를 고치는 갱신 단계이다. 하나의 학습 단계는 순전파로 예측값과 손실을 구하고, 역전파로 기울기를 계산한 뒤, 경사 하강법으로 가중치를 갱신하는 순서로 이루어진다. Keras에서는 model.compile()에서 최적화기(optimizer, 예: SGD, Adam)를 지정하면 model.fit()이 이 과정을 자동으로 반복한다. Adam 같은 최적화기도 경사 하강법을 변형한 방법이다.

11번 답:

다층 퍼셉트론은 입력층, 하나 이상의 은닉층, 출력층으로 구성된 피드포워드 신경망이다. 구조는 다음과 같은 방향으로 확장할 수 있다.

**① 은닉층의 개수 늘리기(깊이 확장)**

은닉층을 하나에서 여러 개로 늘리면 앞 층의 출력이 다음 층의 입력이 되는 중첩 함수가 더 깊어진다. 그 결과 단순한 특징을 조합해 점점 복잡한 패턴을 표현할 수 있으며, 은닉층이 여러 겹인 신경망이 곧 심층 신경망(딥러닝)이다. Keras의 Sequential 모델에서는 Dense 층을 하나 더 추가하면 된다.

**② 은닉층의 유닛 수 늘리기(너비 확장)**

각 은닉층의 유닛(노드) 수, 즉 Dense의 units 값을 키우면 한 층에서 추출할 수 있는 특징의 수가 늘어난다. 예를 들어 그림의 구조(입력 2, 은닉 5, 출력 3)는 파라미터가 (2×5+5)+(5×3+3)=33개이다. 은닉층 유닛을 10개로 늘리면 (2×10+10)+(10×3+3)=63개가 된다. 이처럼 파라미터 수가 늘어나 모델 복잡도가 커지고 더 정밀한 함수를 근사할 수 있다.

**③ 입력층 확장**

입력 특징(feature)의 수가 늘어나면 첫 번째 Dense 층의 input_shape를 바꾼다. 예를 들어 28×28 MNIST 손글씨 이미지는 784개 픽셀 값을 입력으로 쓰므로 Flatten 층으로 펼치거나 input_shape=(784,)로 지정한다.

**④ 출력층 확장**

분류할 클래스가 늘어나면 출력층의 units를 클래스 수에 맞춘다. 이진 분류에서는 출력 유닛 1개에 sigmoid를 쓰지만, 다중 분류에서는 출력 유닛 N개에 softmax를 써서 클래스별 예측 확률을 출력한다. 이때 정답 데이터는 원-핫 인코딩(to_categorical)으로 N차원으로 바꾸고, 손실 함수도 binary_crossentropy에서 categorical_crossentropy로 바꾼다. MNIST(0부터 9까지 숫자)라면 출력 유닛은 10개가 된다.

**⑤ 활성 함수 선택**

층이 깊어질수록 은닉층의 활성 함수가 학습에 큰 영향을 준다. sigmoid는 기울기가 작아 역전파 과정에서 기울기가 점점 사라지는 문제가 생기기 쉽다. 그래서 은닉층에는 주로 ReLU를 사용하고, 출력층에는 문제 유형에 맞는 함수(회귀는 선형, 이진 분류는 sigmoid, 다중 분류는 softmax)를 사용한다.

다음은 그림의 구조를 은닉층 2개로 확장하고 MNIST 분류에 맞게 입력·출력을 바꾼 Keras 예시이다.

```python
model = tf.keras.Sequential([
    tf.keras.layers.Dense(units=128, input_shape=(784,), activation='relu'),  # 은닉층 1
    tf.keras.layers.Dense(units=64, activation='relu'),                       # 은닉층 2 (깊이 확장)
    tf.keras.layers.Dense(units=10, activation='softmax')                     # 출력층 (클래스 10개)
])
model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
              loss='categorical_crossentropy', metrics=['accuracy'])
```

다만 층과 유닛을 무조건 늘리면 파라미터 수와 계산량이 크게 늘어 학습 데이터에만 지나치게 맞추는 과적합이 생길 수 있다. 따라서 검증 데이터의 손실과 정확도를 확인하며 층 수와 유닛 수를 정하고, 필요하면 드롭아웃(Dropout) 같은 규제 기법을 함께 사용하는 것이 바람직하다.
