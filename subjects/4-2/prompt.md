# [System] Markdown 문서 개선 작업 지시

## 1. 기본 정보
- **대상 파일:** `C:\project\airtown\University_KNOU\subjects\4-2\[과목명]\[X강. 강의 제목].md`
- **스타일 참조 파일:** `C:\project\airtown\University_KNOU\subjects\4-2\form.md`
- **정보 수준:** 학부생 전공 수준 (AI를 위한 수학 - 선형대수, 확률/통계 중심)

## 2. 작업 목표
- 대상 파일의 모든 빈 항목을 채우고, 기존 내용을 최신 정보로 수정 및 보완하여 완성도 높은 학습 자료를 만든다.
- **(AI 활용 강화)** NotebookLM과 같은 AI 학습 도우미가 더 깊이 있는 답변을 생성할 수 있도록, **가상 시나리오, 관점별 비교, 오개념 분석** 등 심화 콘텐츠를 추가한다.
- **(수학 특화)** 모든 수학 개념에는 LaTeX 수식을 반드시 포함하고, 해당 수학이 AI/ML에서 어떻게 적용되는지 연결고리를 명시한다.

## 3. 작업 절차 (단락별 순차 진행)
1.  **분석:** 대상 파일의 한 단락(섹션)을 선택한다.
2.  **검색:** 해당 단락의 주제에 대해 인터넷 검색을 수행하여 관련 정보를 수집한다.
3.  **보완:** 수집된 정보를 바탕으로 다음 규칙에 따라 내용을 수정 및 확장한다.
    - **빈 항목 채우기:** 내용이 없는 부분은 검색된 정보로 상세히 채운다.
    - **내용 개선:** 기존 내용은 더 정확하고 이해하기 쉬운 설명으로 개선한다.
    - **수식 포함:** 수학 개념 설명 시 LaTeX 수식($인라인$, $$블록$$)을 반드시 사용한다.
    - **스타일 준수:** '스타일 참조 파일'의 편집 스타일(제목, 목록, 강조 등)과 구조를 엄격히 따른다.
4.  **업데이트:** 해당 단락의 수정이 완료되면 대상 파일을 즉시 업데이트한다.
5.  **반복:** 대상 파일의 모든 단락에 대해 1-4 단계를 반복하여 문서를 완성한다.

## 5. 최종 결과물
- 모든 내용이 채워지고, 스타일 가이드가 적용된 완전한 형태의 Markdown 문서.

## 6. 작업시 참고사항
- 학습목표, 요약 변경 금지, 스타일만 편집해줘.
- 연습문제는 학습 내용을 모두 반영할 수 있도록 문항수를 적절하게 생성해줘.
- form.md 의 스타일 양식을 꼭 준수.
- 수식은 반드시 LaTeX 문법을 사용하고, 인라인 수식($...$)과 블록 수식($$...$$)을 구분해줘.
- 코드로 확인하기 섹션에서는 반드시 실행 가능한 Python 코드를 작성해줘.
- 1번에 출력 할 수 있는 분량이 많으면 오류가 발생하니 1개의 섹션별 생성, 수정해줘.
