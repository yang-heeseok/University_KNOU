# 문제 3 - TensorFlow Playground 하이퍼파라미터 비교 (8점)

## 과제 요약

http://playground.tensorflow.org/ 에서 **학번 끝자리에 따라 분류 데이터셋을 선택**하고,  
**하이퍼파라미터 1개만** 변경하여 신경망 2개를 만든 뒤, 성능을 비교·정리한다.

---

## 요구사항 체크리스트

- [ ] 학번 끝자리에 맞는 **데이터셋 선택**
- [ ] **하이퍼파라미터 1개만** 변경 (나머지는 동일하게 유지)
- [ ] 신경망 2개 각각 결과 **캡처 필수**
- [ ] **1페이지 이상** 작성
- [ ] 두 신경망 성능 비교 및 하이퍼파라미터 특성 정리

## 학번 끝자리별 데이터셋 선택

| 학번 끝자리 | 데이터셋 | 특징 |
|-----------|---------|------|
| **0, 1** | Circle (동심원) | 비선형, 방사형 경계 필요 |
| **2, 3, 4** | Exclusive Or (XOR) | 비선형, 대각선 분리 필요 |
| **5, 6, 7** | Gaussian (가우시안 분포) | 비교적 선형 분리 가능 |
| **8, 9** | Spiral (나선형) | 매우 복잡한 비선형 경계 |

> ✅ **학번 끝자리: 7 → Gaussian (가우시안 분포) 선택 확정**

| 하이퍼파라미터 | 모델 A | 모델 B | 예상 효과 |
|--------------|--------|--------|---------|
| **학습률 (Learning Rate)** | 0.001 | 0.1 | 수렴 속도 및 안정성 차이 |
| **은닉층 수 (Hidden Layers)** | 1층 | 4층 | 표현력 및 과적합 차이 |

| **정규화 (Regularization)** | None | L2 | 과적합 방지 효과 |
| **배치 크기 (Batch Size)** | 1 | 30 | 학습 안정성 및 속도 차이 |

> **추천**: `학습률(Learning Rate)` 변경 → 가장 직관적인 시각적 차이를 보여줌

- **데이터셋: Gaussian (학번 끝자리 7)**
- 노이즈(Noise): 0
- 훈련 비율: 80%
- 은닉층: 1개
- 각 층 뉴런 수: 4개
- 활성화 함수: ReLU
- 정규화: None
- 에포크: 500

> **Gaussian 데이터 특성**: 두 클래스가 각각 정규분포를 따르며 비교적 선형 분리가 가능하다.

## 하이퍼파라미터별 통계학적 의미

### 학습률(Learning Rate) η
- 경사하강법에서 업데이트 보폭 결정
- **낮은 학습률**: 천천히 수렴, 안정적이나 학습 시간 증가
- **높은 학습률**: 빠르게 수렴하지만 발산(oscillation) 위험
- 통계학적 관점: 최적화 문제에서의 수렴 속도와 안정성 트레이드오프

### 은닉층 수 (Network Depth)
- 더 많은 층 → 더 복잡한 함수 표현 가능 (Universal Approximation)
- **얕은 네트워크**: 단순한 경계, 낮은 분산, 높은 편향
- **깊은 네트워크**: 복잡한 경계, 과적합 위험 증가 (분산 증가, 편향 감소)
- 통계학적 관점: **편향-분산 트레이드오프(Bias-Variance Tradeoff)**

### 정규화 (L1/L2 Regularization)
- 가중치에 페널티 부여 → 복잡도 제한
- **L2**: 가중치를 0에 가깝게 줄임 (Ridge 회귀와 동일 원리)
- **L1**: 일부 가중치를 정확히 0으로 (Lasso 회귀와 동일 원리)
- 통계학적 관점: 베이지안 MAP 추정에서의 사전분포 역할

## 결과 해석 포인트

```
훈련 손실 << 테스트 손실  →  과적합(Overfitting) 의심
훈련 손실 ≈ 테스트 손실  →  적절한 일반화
훈련 손실 크고 테스트 손실도 큼  →  과소적합(Underfitting)
```
