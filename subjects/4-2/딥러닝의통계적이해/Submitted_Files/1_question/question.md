# 문제 1 - Teachable Machine 머신러닝 모형 제작 (8점)

## 과제 요약

Teachable Machine(https://teachablemachine.withgoogle.com)을 이용하여 자신의 머신러닝 모형을 만들고, 그 결과를 캡처하여 정리한다.

---

## 요구사항 체크리스트

- [ ] Teachable Machine 사이트 접속 및 프로젝트 생성
- [ ] **데이터 최소 10개 이상** 포함 (클래스별 학습 데이터)
- [ ] 본인이 만든 결과 **반드시 캡처** (학습 화면, 분류 결과 포함)
- [ ] **1페이지 이상** 작성
- [ ] 결과에 대한 설명 포함

---

## 작성 전략

### 1. 프로젝트 선택

Teachable Machine은 세 가지 유형을 제공한다:
- **Image Project** (이미지 분류) → 가장 직관적이고 결과가 명확함 ★ 추천
- Audio Project (오디오 분류)
- Pose Project (자세 인식)

> **선택 주제**: 수학 문항 이미지 4분류 프로젝트
> - 응답 방식(객관식/주관식) × 지문 구성(단독/그림삽입) 조합으로 4개 클래스 구성
> - 셋트형보다 **그림 포함 문항**이 기출에서 사례가 훨씬 많아 데이터 확보에 유리

### 2. 클래스 정의 및 데이터 구성 계획

| 클래스 | 유형명 | 시각적 특징 | 데이터 수 |
|--------|-------|-----------|---------|
| Class 1 | **단독_객관식** | 선택지(①~⑤) 있음, 그림 없음 | 12장 |
| Class 2 | **단독_주관식** | 선택지 없음, 그림 없음 | 10장 |
| Class 3 | **그림삽입_객관식** | 선택지(①~⑤) 있음, 그림/도형 포함 | 12장 |
| Class 4 | **그림삽입_주관식** | 선택지 없음, 그림/도형 포함 | 10장 |

**총 44장** (클래스당 불균형 최소화)

> 데이터 출처: 수능 및 수학 모의고사 기출 PDF (EBSi, 한국교육과정평가원 공개 자료) 캡처

---

## 보고서 작성 구성 (1페이지 이상)

### (1) 프로젝트 개요
- 주제 선정 이유
- 분류 클래스 설명

### (2) 데이터 수집 과정
- 각 클래스별 데이터 수 명시
- 데이터 수집 방법 설명
- **[캡처1]** Teachable Machine 데이터 입력 화면

### (3) 모델 학습
- "Training" 버튼 클릭 후 학습 진행
- **[캡처2]** 학습 완료 화면 (Training 완료 상태)

### (4) 결과 확인 및 분석
- 미리보기(Preview) 창에서 실시간 분류 테스트
- **[캡처3]** 분류 결과 화면 (Confidence 수치 포함)
- 각 클래스의 분류 정확도 및 신뢰도 분석

### (5) 모델 내보내기 (선택)
- "Export Model" → Tensorflow.js, TFLite, Keras 형식으로 저장 가능

---

## 핵심 설명 포인트 (통계학적 관점)

1. **전이학습(Transfer Learning)**: Teachable Machine은 MobileNet 등 사전학습된 모델을 기반으로 동작
2. **분류 신뢰도(Confidence)**: 각 클래스에 대한 확률값 → 소프트맥스(Softmax) 출력
3. **데이터 불균형**: 클래스별 데이터 수가 비슷해야 편향 없는 학습 가능
4. **오버피팅 위험**: 데이터가 너무 적거나 유사하면 일반화 성능 저하

---

## 주의사항

- 결과 화면 캡처 시 **본인 학번/이름이 보이도록** 준비할 것
- 스크린샷은 고해상도로 저장
- 단순 캡처만 나열하지 말고, 각 캡처에 대한 **해석과 설명** 반드시 추가
- AI 생성 문구 그대로 사용 금지 → 본인의 언어로 재정리
