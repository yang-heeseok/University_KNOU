### 1.3 단일 변수 회귀 일괄 적합 (`fit_one`)

```r
xvars <- setdiff(names(mtcars), "mpg")

fit_one <- function(v) {
  f <- as.formula(paste("mpg ~", v))
  m <- lm(f, data = mtcars); s <- summary(m)
  data.frame(
    var      = v,
    beta     = unname(coef(m)[2]),
    se       = unname(coef(s)[2, "Std. Error"]),
    t_value  = unname(coef(s)[2, "t value"]),
    p_value  = unname(coef(s)[2, "Pr(>|t|)"]),
    R2       = s$r.squared,
    adj_R2   = s$adj.r.squared,
    F_stat   = unname(s$fstatistic[1]),
    sigma    = s$sigma,
    AIC      = AIC(m), BIC = BIC(m)
  )
}

res <- do.call(rbind, lapply(xvars, fit_one))
res <- res[order(-res$R2), ]
print(res, row.names = FALSE, digits = 4)
```

### 1.4 베이스 모형 + 1개 변수 추가 (`fit_two`)

```r
library(car)
base   <- lm(mpg ~ wt, data = mtcars)
xvars2 <- setdiff(names(mtcars), c("mpg", "wt"))

fit_two <- function(v) {
  f  <- as.formula(paste("mpg ~ wt +", v))
  m  <- lm(f, data = mtcars); s <- summary(m)
  a  <- anova(base, m)            # 부분 F-검정
  vifs <- car::vif(m)
  data.frame(
    add_var   = v,
    beta_new  = unname(coef(m)[v]),
    p_new     = unname(coef(s)[v, "Pr(>|t|)"]),
    R2        = s$r.squared, adj_R2 = s$adj.r.squared,
    sigma     = s$sigma,
    AIC       = AIC(m), BIC = BIC(m),
    partial_F = a$F[2], partial_p = a$`Pr(>F)`[2],
    VIF_wt    = unname(vifs["wt"]), VIF_new = unname(vifs[v])
  )
}

res2 <- do.call(rbind, lapply(xvars2, fit_two))
res2 <- res2[order(-res2$adj_R2), ]
print(res2, row.names = FALSE, digits = 4)
```

### 1.5 회귀 진단 4종 세트

```r
fit <- lm(mpg ~ wt + cyl, data = mtcars)
summary(fit); confint(fit)
car::vif(fit)
anova(base, fit)                   # 부분 F-검정 (단순 vs 중회귀 비교)

par(mfrow = c(2, 2)); plot(fit); par(mfrow = c(1, 1))
shapiro.test(resid(fit))           # 정규성
lmtest::bptest(fit)                # 등분산성
```

### 1.6 표준화 회귀계수 — 3가지 방법

```r
# 방법 1 (가장 깔끔)
mtcars_std <- as.data.frame(scale(mtcars))
fit_std    <- lm(mpg ~ wt + cyl, data = mtcars_std)
summary(fit_std); confint(fit_std)

# 방법 2 (한 줄)
library(lm.beta); lm.beta(fit)

# 방법 3 (검산용 손계산)
sd_y <- sd(mtcars$mpg); sd_x <- sd(mtcars$wt)
coef(fit)["wt"] * sd_x / sd_y
```

> **검증 포인트**: 세 방법의 표준화 계수가 모두 일치하고, 표준화 후에도 `R²·F·p값·t값`이 원래 모형과 **완전히 동일** 해야 한다.

## 2. 본문 집필 — 문항당 5단 구조

각 문항을 다음 5절로 나누면 채점 배점에 빠짐없이 응답할 수 있다.

```
(1) 분석 절차          ← "어떻게 결정할 것인가" 사전 명시
(2) 결과 (표·이미지)   ← R 출력을 그대로 첨부 + 마크다운 표로 재구성
(3) 결과 해석          ← 1위/2위/하위 변수의 패턴, 다중공선성 등
(4) 진단/검증          ← Shapiro, BP, VIF, partial F 등
(5) 결론               ← 채택 모형을 박스($\boxed{...}$)로 강조
```

### 표 작성 기준

- **1위/채택 항목만 bold** 처리 (가독성 ↑)
- 수치는 **3자리 유효숫자**로 통일 (Shapiro p = `0.104`, BP p = `0.841` 등)
- 단위는 행/열 헤더에 명시 (예: `mpg / 1000lb`)

### 결론 작성 기준

- **모든 비교 지표를 한 단락 내 나열**: adj.R², partial F, AIC, σ̂, VIF
- **회귀계수 + 95% 신뢰구간 + p값**을 함께 언급
- **잔차 가정 충족 여부**를 명시
- 채택 모형은 `$$\boxed{\widehat{Y} = ...}$$` 으로 박스 처리

## 3. 자주 활용한 통계학적 판단 기준

| 지표 | 임계치 | 비고 |
|---|---|---|
| VIF | < 5 (보수적 < 10) | 다중공선성 |
| ΔAIC | > 10: 매우 강한 개선 / 4~7: 의미 있음 | Burnham & Anderson |
| Shapiro p | > 0.05 → 정규성 가정 OK | 표본 ≥ 30이면 robust |
| BP p | > 0.05 → 등분산성 가정 OK | — |
| 회귀계수 | 95% CI가 0을 포함하지 않으면 유의 | p < 0.05 와 동치 |
| R² (단순회귀) | r² 와 동일 | 중회귀에서는 다중상관계수² |

### 단순회귀 → 중회귀 확장 시 주의사항

1. **R² 는 단조증가** → adj.R², AIC, partial F 로 비교
2. **계수의 절댓값 비교 불가** (단위 다름) → 표준화 회귀계수 사용
3. **이산형 변수의 표준화는 부적절** (예: cyl ∈ {4,6,8} 의 1 SD ≈ 1.79개 → 비실재적)
4. **다중공선성 점검 필수**: 후보 변수가 기존 변수와 강상관(예: wt ↔ cyl r=0.78)이면 VIF 확인

### 4.1 PDF 변환 (`scripts/md-to-pdf.js`)

```bash
node scripts/md-to-pdf.js "subjects/.../report.md" \
  --margin-top 9mm --margin-bottom 9mm \
  --margin-left 20mm --margin-right 20mm
```

| 옵션 | 기본값 | 비고 |
|---|---|---|
| `--margin-top/bottom` | 6mm / 6mm | 본문 위·아래 여백 |
| `--margin-left/right` | 20mm / 40mm | 본문 좌·우 여백 |
| `--image-scale` | (없음) | 이미지 일괄 축소 (예: `80%`) |
| `-o, --output` | (입력 파일명).pdf | 출력 경로 지정 |

### 4.2 알려진 이슈 + 해결

| 이슈 | 원인 | 해결 |
|---|---|---|
| **PDF 이미지 누락** | `content` + `basedir` 조합에서 한글/공백 경로 처리 불안정 | 스크립트가 `path` 옵션으로 md-to-pdf 호출 (file:// 로 직접 navigate) |
| **`corrplot`/`lmtest` 없음 에러** | 패키지 미설치 | `install.packages("...")` |

## 5. 심층 감사 체크리스트

보고서 제출 전 다음 항목을 점검:

- [ ] **사실 정확성**: 인용 연도·저널명·저자 (예: 갈톤 1885 강연 / 1886 발표)
- [ ] **통계 용어**: SSR(회귀제곱합) vs RSS(잔차제곱합) 혼동 여부
- [ ] **수치 일관성**: 본문/결론에서 같은 값의 자릿수 통일
- [ ] **계수 해석**: "다른 변수를 고정한 상태에서" 표현 누락 여부
- [ ] **단위 명시**: β̂의 단위(예: mpg/1000lb)
- [ ] **회귀 가정**: 정규성·등분산성·다중공선성 모두 검정
- [ ] **목차 앵커**: 한글 헤딩의 마크다운 앵커 규칙 (특수문자 제거, 공백 → `-`)
- [ ] **참고문헌**: APA-style (저자, 연도, 제목, 저널, 권호)
- [ ] **PDF 검증**: 이미지·표·페이지 분할 확인

## 6. 1회용 트랜스크립트 → 재사용 자산화

이번 작업에서 다음을 자산화했다.

1. **`scripts/md-to-pdf.js` 개선**: `path` 옵션 분기 추가로 한글 경로 + 이미지 임베드 안정화 → 다른 과제에도 그대로 사용 가능

4. **3자리 유효숫자 규칙 + 박스 결론**: 일관된 보고서 톤
