**[과제명] 공공데이터포털 데이터 사용**

\*반드시 [과제작성 시 지시사항]을 읽고 과제를 수행하시오.

**문 1. API 인증키 발급 및 데이터 수집: 한국농수산식품유통공사 일별 도,소매 가격정보 조회의 데이터를 Open API를 활용하여 수집하시오. (10점)**

**문 1-1.** 공공데이터포털(https://data.go.kr)에서 "한국농수산식품유통공사_일별 도,소매 가격정보 조회"(https://www.data.go.kr/data/15156057/openapi.do)를 검색하여 활용신청 과정을 거쳐 인증키를 발급받고, 발급받은 인증키 정보를 포함한 화면을 캡처하여 첨부하시오. (개인정보 보호를 위해 인증키 일부는 마스킹 처리하시오.) (3점)

**문 1-2.** API를 호출하는 파이썬 코드를 작성하고, 2015년부터 2024년까지 서울 가락도매시장의 배추(품종: 봄/여름(고랭지)/가을/월동) 가격 데이터를 수집하는 프로그램을 작성하시오. 파이썬 코드와 API 호출 성공을 확인할 수 있는 실행 결과를 캡처하여 첨부하시오. (7점)

※ 연도·품종별 데이터 수집은 다음의 url 형식을 사용

```text
https://apis.data.go.kr/B552845/perDay/price?serviceKey={본인의_인증키}&pageNo=1&numOfRows=200&returnType=JSON&cond[exmn_ymd::GTE]={연도}0101&cond[exmn_ymd::LTE]={연도}1231&cond[se_cd::EQ]=02&cond[ctgry_cd::EQ]=200&cond[item_cd::EQ]=211&cond[grd_cd::EQ]=04&cond[sgg_cd::EQ]=1101&cond[mrkt_cd::EQ]=0110211&cond[vrty_cd::EQ]={품종코드}
```

※ 필수 코드 값 (이 과제에서 사용할 값만 정리하였음. 그 외 전체 코드 목록이나 API 상세 명세는 "한국농수산식품유통공사_일별 도,소매 가격정보 조회" 페이지의 참고문서에서 확인할 수 있음.)

| 파라미터 | 코드 | 의미 |
| --- | --- | --- |
| cond[se_cd::EQ] | 02 | 구분코드 — 중도매(도매) |
| cond[ctgry_cd::EQ] | 200 | 부류코드 — 채소류 |
| cond[item_cd::EQ] | 211 | 품목코드 — 배추 |
| cond[grd_cd::EQ] | 04 | 등급코드 — 상품 |
| cond[sgg_cd::EQ] | 1101 | 시군구코드 — 서울 |
| cond[mrkt_cd::EQ] | 0110211 | 시장코드 — 가락도매 |
| cond[vrty_cd::EQ] | 01 / 02 / 03 / 06 | 품종코드 — 아래 표 참고 |

※ 배추는 출하 시기에 따라 유통되는 품종 자체가 바뀌기 때문에, 품종코드 하나로는 1년 전체가 채워지지 않음.

| 품종코드 | 품종명 | 대략적 출하 시기 |
| --- | --- | --- |
| 01 | 봄배추 | 5~7월 |
| 02 | 여름배추(고랭지) | 7~11월 |
| 03 | 가을배추 | 10~12월 |
| 06 | 월동배추 | 1~5월(+12월 일부) |

※ 동작 확인 예시 — 아래 조건으로 호출하면 정확히 66건이 나와야함. 이보다 적게 나오거나(특히 0건) 다른 숫자가 나온다면 URL의 코드 값 확인이 필요 (0건은 API 오류가 아니라 파라미터 조합이 실제로 존재하는 값과 불일치함을 의미)

```text
https://apis.data.go.kr/B552845/perDay/price?serviceKey={본인의_인증키}&pageNo=1&numOfRows=200&returnType=JSON&cond[exmn_ymd::GTE]=20150101&cond[exmn_ymd::LTE]=20151231&cond[se_cd::EQ]=02&cond[ctgry_cd::EQ]=200&cond[item_cd::EQ]=211&cond[grd_cd::EQ]=04&cond[sgg_cd::EQ]=1101&cond[mrkt_cd::EQ]=0110211&cond[vrty_cd::EQ]=01
```

→ 응답의 response.body.totalCount 값이 66이면 정상

※ 가격 필드(exmn_dd_prc)의 단위는 "원/kg"이 아니라 시장에서 실제 거래되는 포장 단위 (예: "kg(그물망 3포기)")입니다. 절대적인 kg당 가격보다는 연도별·계절별 상대적인 변화 추이를 파악하는데 활용

**문 2. 데이터 변환 및 전처리: 수집한 데이터를 분석에 적합한 형태로 변환하시오. (8점)**

**문 2-1.** 수집한 JSON 형태의 데이터를 pandas DataFrame으로 변환하고, 데이터의 기본 정보를 출력하는 파이썬 코드와 실행 결과를 첨부하시오. (4점)

**문 2-2.** 연도별, 계절별 분석을 위해 조사일자(exmn_ymd) 컬럼을 활용하여 연도(year)와 계절(season) 컬럼을 추가하는 전처리 코드를 작성하고, 변환 결과를 확인할 수 있는 출력 결과를 첨부하시오. (4점)

※ 계절 구분: 봄(3-5월), 여름(6-8월), 가을(9-11월), 겨울(12-2월)

**문 3. 데이터 시각화: 전처리된 데이터를 활용하여 다음의 시각화를 수행하시오. (8점)**

**문 3-1.** 연도별 배추 평균 가격(exmn_dd_prc) 변화량을 선 그래프로 시각화하고, 그래프에 자신의 학번 뒤 4자리를 제목에 포함하여 저장하시오. (예: "연도별 배추 평균 가격 변화 - 1234") 시각화 코드와 생성된 그래프를 첨부하시오. (4점)

**문 3-2.** 계절별 배추 평균 가격을 막대 그래프로 시각화하고, 각 막대에 구체적인 수치를 표시하시오. 시각화 코드와 생성된 그래프를 첨부하시오. (4점)

**문 4. 데이터 분석 및 해석: 시각화 결과를 바탕으로 연도별·계절별 배추 가격 변화에서 나타나는 주요 트렌드를 찾아 분석하고, 그 원인을 추론하여 500자 정도로 설명하시오. (예: 여름철 고랭지배추 수급난에 따른 가격 급등, 이상 기후에 따른 작황 변화 등) (4점)**
